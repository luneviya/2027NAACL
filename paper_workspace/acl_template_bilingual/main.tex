\begin{abstract}
Contrastive code search is commonly trained with in-batch, random, or statically mined negatives, although inference errors are determined by the few high-scoring candidates returned by the trained retriever. We present \method{}, a failure-calibrated refinement framework that freezes an initial retriever, harvests its high-ranked unpaired candidates, and turns them into targeted contrastive supervision. A separately weighted failure-candidate loss refines global query--code representations according to their positive--negative score margins; an optional inference stage then applies token-level MaxSim and Global--Local Score Fusion only within the retrieved top-\(K\). Under a matched local protocol on the six-language CodeSearchNet benchmark, \method{}-Global raises macro-averaged MRR from 79.77 to 80.57, and \method{}-Rerank reaches 81.06. The complete system improves MRR by 1.29 points over the initial retriever, with a paired-bootstrap 95\% confidence interval of [1.11, 1.47] over test queries. Budget-matched candidate controls favor Failure Candidate Harvesting over random and static alternatives, and rank-conditioned analysis locates the largest gains among queries whose paired code initially ranks 2--10. The full pipeline can be instantiated with CoCoSoDa, UniXcoder, and GraphCodeBERT, with MaxSim improving MRR for each refined checkpoint.
% 中文：对比式代码搜索通常使用批内、随机或静态挖掘的负样本进行训练，但推理错误实际由训练完成的检索器返回的少量高分候选决定。本文提出 \method{}，一种失败校准的细化框架：它冻结初始检索器，挖掘其高排名未配对候选，并将这些候选转化为有针对性的对比监督。单独加权的失败候选损失根据正负样本分数间隔细化全局查询—代码表示；可选的推理阶段随后仅在检索得到的前 \(K\) 个候选内应用词元级 MaxSim 和全局—局部分数融合。在六语言 CodeSearchNet 基准的协议一致本地评测中，\method{}-Global 将宏平均 MRR 从 79.77 提升至 80.57，\method{}-Rerank 进一步达到 81.06。完整系统相对于初始检索器提升 1.29 个 MRR 点，测试查询上的配对 bootstrap 95\% 置信区间为 [1.11, 1.47]。预算匹配的候选对照表明，失败候选挖掘优于随机与静态替代方案；按排名分层的分析则显示，最大收益来自配对代码初始位于第 2--10 名的查询。完整流程可分别使用 CoCoSoDa、UniXcoder 和 GraphCodeBERT 实例化，且 MaxSim 均能提高相应细化检查点的 MRR。
\end{abstract}

\section{Introduction}
\label{sec:introduction}

Code search connects natural-language intent with executable implementations, allowing developers to retrieve relevant snippets from large repositories. Modern systems commonly encode a query and each code candidate independently, then rank the corpus by similarity in a shared representation space~\citep{CodeBERT,GraphCodeBERT,UniXcoder}. This dual-encoder design supports efficient full-corpus retrieval, while contrastive pre-training and fine-tuning improve the alignment between paired queries and code~\citep{CodeRetriever,CoCoSoDa}. Its effectiveness, however, depends critically on which unpaired examples define the competing side of the contrastive objective.
% 中文：代码搜索将自然语言意图与可执行实现联系起来，使开发者能够从大规模代码库中检索相关代码片段。现代系统通常分别编码查询与每个候选代码，再根据共享表示空间中的相似度对整个语料库排序~\citep{CodeBERT,GraphCodeBERT,UniXcoder}。这种双编码器设计支持高效的全库检索，而对比式预训练与微调则改善配对查询和代码之间的对齐~\citep{CodeRetriever,CoCoSoDa}。然而，其效果关键取决于哪些未配对样本构成对比目标中的竞争一侧。

Standard objectives draw negatives from the current minibatch, random sampling, or a static pool constructed independently of the final retriever's rankings. Such negatives can be useful without matching the candidates that actually determine errors at inference time. Once training is complete, the paired code is outranked only by corpus items assigned an equal or larger score; in practice, these comparisons are concentrated among a small set of high-ranked alternatives. This distinction is especially visible in \emph{Retrieved-but-Mis-ranked Cases}, where the paired code is already recalled near the top but remains below one or more competing candidates. Figure~\ref{fig:problem_setting} illustrates this setting. Improving these cases requires supervision drawn from the full-corpus rankings produced by the initial retriever.
% 中文：标准目标从当前小批量、随机采样或独立于最终检索器排序构建的静态候选池中获取负样本。这些负样本可能有效，却未必对应推理时真正决定错误的候选。训练完成后，只有得分不低于配对代码的语料项才会使其排名后移；在实践中，这类比较集中于少量高排名替代候选。该区别在“已检索但排序错误案例”（Retrieved-but-Mis-ranked Cases）中尤为明显：配对代码已经在顶部附近被召回，却仍位于一个或多个竞争候选之后。图~\ref{fig:problem_setting} 展示了这一情形。要改善这些案例，监督信号需要来自初始检索器产生的全库排序。

We therefore propose \method{}, a failure-calibrated contrastive refinement framework with three stages. \emph{Failure Candidate Harvesting} freezes the trained initial retriever and collects its highest-ranked unpaired code for every training query after excluding the paired example and candidates sharing its URL. \emph{Failure-Calibrated Contrastive Refinement} preserves the base objective and adds a separately weighted contrastive loss over the harvested candidates. Optional \emph{Dual-Granularity Reranking} applies token-level MaxSim to the global top-\(K\) and performs \emph{Global--Local Score Fusion}. Harvesting and refinement form the training procedure; reranking adds no trainable parameters but incurs explicit inference cost.
% 中文：为此，我们提出 \method{}，一种包含三个阶段的失败校准对比细化框架。\emph{失败候选挖掘（Failure Candidate Harvesting）}冻结训练完成的初始检索器，在排除配对样本及共享其 URL 的候选后，为每个训练查询收集排名最高的未配对代码。\emph{失败校准对比细化（Failure-Calibrated Contrastive Refinement）}保留基础目标，并在挖掘候选上增加单独加权的对比损失。可选的\emph{双粒度重排（Dual-Granularity Reranking）}对全局前 \(K\) 个候选应用词元级 MaxSim，并执行\emph{全局—局部分数融合（Global--Local Score Fusion）}。候选挖掘与细化构成训练流程；重排不增加可训练参数，但会带来明确的推理成本。

The positive--negative score margin explains how harvested candidates affect refinement. A small or negative margin produces a larger loss contribution, so candidates closest to displacing the paired code exert the strongest optimization pressure. The resulting update acts on the score comparisons that determine rank, while MRR remains an evaluation metric rather than a training objective. Consistent with this analysis, the largest empirical gains occur when the paired code is initially ranked 2--10.
% 中文：正负样本分数间隔说明了挖掘候选如何影响细化。当间隔较小或为负时，候选产生更大的损失贡献，因此最接近挤压配对代码排名的候选会施加最强的优化压力。由此产生的更新作用于决定排名的分数比较，而 MRR 仍是评测指标而非训练目标。与这一分析一致，当配对代码初始位于第 2--10 名时，实验收益最大。

Under a matched local evaluation protocol on all six CodeSearchNet languages~\citep{CodeSearchNet}, \method{}-Global improves macro-averaged MRR from 79.77 to 80.57 and R@1 from 70.72 to 71.90. Adding the optional reranker reaches 81.06 MRR and 72.64 R@1. Candidate-selection controls show that retriever-mined Failure Candidates outperform random and static alternatives under the same added-candidate budget. Paired-bootstrap intervals quantify test-query sampling uncertainty for the fixed checkpoints, and experiments with three encoder architectures examine the applicability of the complete pipeline.
% 中文：在全部六种 CodeSearchNet 语言~\citep{CodeSearchNet}上的协议一致本地评测中，\method{}-Global 将宏平均 MRR 从 79.77 提升至 80.57，并将 R@1 从 70.72 提升至 71.90；加入可选重排器后达到 81.06 MRR 和 72.64 R@1。候选选择对照表明，在相同的附加候选预算下，由检索器挖掘的失败候选优于随机和静态替代方案。配对 bootstrap 区间衡量固定检查点上的测试查询采样不确定性，三种编码器架构上的实验则考察完整流程的适用性。

Our contributions are threefold:
% 中文：本文的贡献有三点：
\begin{itemize}
  \item We introduce \method{}, a failure-calibrated contrastive refinement framework that converts high-ranked unpaired candidates from a frozen initial retriever into model-specific supervision while retaining efficient full-corpus dual-encoder retrieval.
  % 中文：我们提出 \method{}，一种失败校准对比细化框架。它将冻结初始检索器返回的高排名未配对候选转化为模型特定监督，同时保留高效的全库双编码器检索。
  \item We connect the refinement signal to positive--negative score margins and isolate its source with budget-matched candidate controls and rank-conditioned analysis. The evidence attributes the principal gains to repairing near-top misrankings rather than to broader top-10 coverage.
  % 中文：我们将细化信号与正负样本分数间隔联系起来，并通过预算匹配的候选对照和按排名分层的分析隔离其来源。证据表明，主要收益来自修复接近顶部的错误排序，而不是扩大前 10 名的覆盖率。
  \item We provide a controlled six-language evaluation in which global refinement improves the matched initial retriever by 0.80 MRR points, and optional Dual-Granularity Reranking raises the complete improvement to 1.29 points, with explicit uncertainty and efficiency reporting.
  % 中文：我们在六种语言上开展受控评测：全局细化相对于协议一致的初始检索器提升 0.80 个 MRR 点，可选的双粒度重排将完整系统的提升扩大至 1.29 个点，并显式报告不确定性与效率。
\end{itemize}

\section{Related Work}
\label{sec:related_work}

\subsection{Neural Code Search}

Neural code search learns a common representation space for natural-language queries and source code. Pre-trained encoders including CodeBERT, GraphCodeBERT, and UniXcoder supply transferable code--text representations~\citep{CodeBERT,GraphCodeBERT,UniXcoder}, while CodeRetriever and CoCoSoDa strengthen retrieval through large-scale or augmented contrastive learning~\citep{CodeRetriever,CoCoSoDa}. Recent systems further incorporate task-specific negative construction and auxiliary relevance signals~\citep{AAAIUA,HedgeCode}. These approaches primarily improve the encoder, pre-training signal, or initial contrastive objective. \method{} operates after an initial retriever has been trained: it uses the full-corpus rankings produced by that retriever to construct a targeted second-stage objective, making the framework complementary to the underlying encoder architecture.
% 中文：神经代码搜索为自然语言查询与源代码学习共享表示空间。CodeBERT、GraphCodeBERT 和 UniXcoder 等预训练编码器提供可迁移的代码—文本表示~\citep{CodeBERT,GraphCodeBERT,UniXcoder}，CodeRetriever 与 CoCoSoDa 则通过大规模或增强式对比学习强化检索能力~\citep{CodeRetriever,CoCoSoDa}。近期系统还引入任务特定的负样本构造和辅助相关性信号~\citep{AAAIUA,HedgeCode}。这些方法主要改进编码器、预训练信号或初始对比目标。\method{} 则作用于初始检索器训练完成之后：它利用该检索器产生的全库排序构造有针对性的第二阶段目标，因此可与底层编码器架构互补。

\subsection{Hard Negatives and Late Interaction}

Hard-negative mining replaces easy random negatives with candidates that better challenge the current representation space. Dense-retrieval methods such as ANCE and RocketQA retrieve negatives from an index or iteratively denoise them, showing the value of aligning training candidates with search behavior~\citep{ANCE,RocketQA}; code-search work similarly constructs informative negatives through uncertainty-aware sampling~\citep{AAAIUA}. Failure Candidate Harvesting is a method-specific instance of retrieval-based mining: it uses full-corpus rankings from a frozen, fully trained initial retriever and then applies a separate refinement stage. Orthogonally, late-interaction models preserve token representations and aggregate token-wise matches; ColBERT's MaxSim is a representative formulation~\citep{ColBERT}. We adopt MaxSim only in the optional Dual-Granularity Reranking stage, restrict it to the global top-\(K\), standardize both score types within that set, and apply Global--Local Score Fusion. This design trades additional inference cost for finer discrimination among high-ranked candidates.
% 中文：困难负样本挖掘以更能挑战当前表示空间的候选替代简单随机负样本。ANCE 与 RocketQA 等稠密检索方法从索引中检索负样本或迭代去噪，说明使训练候选与搜索行为对齐的价值~\citep{ANCE,RocketQA}；代码搜索工作也通过不确定性感知采样构造信息量更高的负样本~\citep{AAAIUA}。失败候选挖掘是检索式挖掘在本文中的方法特定实例：它使用冻结且训练完成的初始检索器产生的全库排序，再执行独立的细化阶段。与此正交，后期交互模型保留词元表示并聚合逐词元匹配；ColBERT 的 MaxSim 是代表性形式~\citep{ColBERT}。我们仅在可选的双粒度重排阶段采用 MaxSim，将其限制在全局前 \(K\) 个候选内，在该集合中分别标准化两类分数并执行全局—局部分数融合。该设计以额外推理成本换取对高排名候选的更细粒度区分。

\section{Method}
\label{sec:method}

Failure Candidate Harvesting collects high-ranked unpaired alternatives from a frozen initial retriever, and Failure-Calibrated Contrastive Refinement uses these model-specific candidates to update the global retrieval space. The refined dual encoder retrieves from the complete corpus; optional Dual-Granularity Reranking then combines sequence-level and token-level evidence within the retrieved top-\(K\).

\subsection{Problem Formulation}
\label{sec:problem_formulation}

Let \(\mathcal{D}=\{(q_i,c_i^+)\}_{i=1}^{N}\) denote a code-search training set, where \(q_i\) is a natural-language query and \(c_i^+\) is its paired code snippet. A dual encoder maps queries and code into a shared space through \(f_\theta\) and \(g_\theta\). After \(\ell_2\) normalization, their global retrieval score is
% 中文：设 \(\mathcal{D}=\{(q_i,c_i^+)\}_{i=1}^{N}\) 表示代码搜索训练集，其中 \(q_i\) 是自然语言查询，\(c_i^+\) 是与之配对的代码片段。双编码器分别通过 \(f_\theta\) 和 \(g_\theta\) 将查询与代码映射到共享空间。经过 \(\ell_2\) 归一化后，其全局检索分数定义为
\begin{equation}
  s_\theta(q,c)=f_\theta(q)^{\top}g_\theta(c).
  \label{eq:global_score}
\end{equation}

For a competing candidate \(c^-\), define the score margin as \(\mu_\theta(q_i,c^-)=s_\theta(q_i,c_i^+)-s_\theta(q_i,c^-)\). The rank of the paired code can then be written as
% 中文：对于竞争候选 \(c^-\)，定义分数间隔 \(\mu_\theta(q_i,c^-)=s_\theta(q_i,c_i^+)-s_\theta(q_i,c^-)\)。配对代码的排名可写为
\begin{equation}
  \operatorname{rank}_\theta(c_i^+\mid q_i)
  =1+\sum_{c\in\mathcal{C}\setminus\{c_i^+\}}
  \mathbb{I}\!\left[\mu_\theta(q_i,c)\leq 0\right],
  \label{eq:rank_margin}
\end{equation}
where \(\mathcal{C}\) is the retrieval corpus. Equation~\ref{eq:rank_margin} makes the relevant supervision target explicit: ranking errors are determined by candidates whose scores meet or exceed that of the paired code. Because conventional in-batch or statically mined negatives are selected before the final retriever is observed, they need not coincide with these model-specific competitors. \method{} therefore conditions refinement on the ranking behavior of a trained initial retriever.
% 中文：其中 \(\mathcal{C}\) 表示检索语料库。式~\ref{eq:rank_margin} 明确了与排序直接相关的监督对象：排序错误由得分达到或超过配对代码的候选决定。常规批内负例或静态挖掘负例是在最终检索器行为被观察之前选取的，因此未必与这些模型特定的竞争候选一致。基于此，\method{} 根据训练完成的初始检索器所产生的排序行为开展细化。

\subsection{Failure Candidate Harvesting}
\label{sec:failure_harvesting}

We first train an initial retriever with the underlying contrastive code-search objective and freeze its parameters \(\theta_0\). For every training query, the frozen model retrieves from the training code corpus. Let \(\mathcal{E}_i\) contain the paired code and all candidates sharing its URL. We remove \(\mathcal{E}_i\) and retain the \(M\) highest-scoring candidates:
% 中文：我们首先使用基础对比式代码搜索目标训练初始检索器，并冻结其参数 \(\theta_0\)。对于每个训练查询，冻结模型在训练代码语料库中执行检索。令 \(\mathcal{E}_i\) 包含配对代码以及与其共享 URL 的所有候选；移除 \(\mathcal{E}_i\) 后，保留得分最高的 \(M\) 个候选：
\begin{equation}
  \mathcal{H}_i=
  \operatorname{Top}_{M}^{s_{\theta_0}(q_i,\cdot)}
  (\mathcal{C}_{\mathrm{train}}\setminus\mathcal{E}_i),
  \qquad
  \mathcal{F}_i=
  \operatorname{Top}_{m}^{s_{\theta_0}(q_i,\cdot)}(\mathcal{H}_i).
  \label{eq:fc_pool}
\end{equation}

We call members of \(\mathcal{F}_i\) \emph{failure candidates}: they are the initial retriever's strongest unpaired alternatives for \(q_i\) and directly instantiate the score comparisons that determine rank in Equation~\ref{eq:rank_margin}. This is an operational designation based on benchmark pairing and retrieval rank; it does not assume that every unpaired candidate is semantically invalid. The pool is generated once from the frozen initial retriever. During refinement, we sample \(r\) candidates from its top \(m\) entries for each query, preserving model specificity without repeating corpus-wide retrieval at every update.
% 中文：我们将 \(\mathcal{F}_i\) 中的元素称为“失败候选”：它们是初始检索器针对 \(q_i\) 返回的最强未配对替代项，并直接构成式~\ref{eq:rank_margin} 中决定排名的分数比较。该名称是依据基准配对关系和检索排名给出的操作性定义，并不假设每个未配对候选在语义上都无效。候选池仅由冻结的初始检索器生成一次；细化时，每个查询从池中排名前 \(m\) 的条目中采样 \(r\) 个候选，从而保留模型特异性，同时避免在每次参数更新时重复执行全语料库检索。

\subsection{Failure-Calibrated Contrastive Refinement}
\label{sec:failure_refinement}

Starting from \(\theta_0\), we retain the initial retriever's contrastive objective \(\mathcal{L}_{\mathrm{base}}\) and introduce a listwise objective over the harvested candidates. For a minibatch \(\mathcal{B}\), let \(\mathcal{S}_i\subseteq\mathcal{F}_i\) contain the \(r\) candidates sampled for query \(q_i\). The failure-candidate loss is
% 中文：以 \(\theta_0\) 为起点，我们保留初始检索器的对比目标 \(\mathcal{L}_{\mathrm{base}}\)，并对挖掘得到的候选引入 listwise 目标。对于小批量 \(\mathcal{B}\)，设 \(\mathcal{S}_i\subseteq\mathcal{F}_i\) 包含为查询 \(q_i\) 采样的 \(r\) 个候选。失败候选损失定义为
\begin{equation}
  \mathcal{L}_{\mathrm{FC}}^{i}
  =-\log\frac{\exp(s_\theta(q_i,c_i^+)/\tau_f)}
  {\exp(s_\theta(q_i,c_i^+)/\tau_f)
   +\sum_{c\in\mathcal{S}_i}\exp(s_\theta(q_i,c)/\tau_f)},
  \label{eq:fc_loss}
\end{equation}
and the complete refinement objective is
% 中文：完整的细化目标为
\begin{equation}
  \mathcal{L}_{\mathrm{ref}}
  =\mathcal{L}_{\mathrm{base}}
  +\frac{\lambda_f}{|\mathcal{B}|}
   \sum_{i\in\mathcal{B}}\mathcal{L}_{\mathrm{FC}}^{i}.
  \label{eq:refinement_loss}
\end{equation}

\paragraph{Score-margin interpretation.}
The added term admits a direct score-margin form,
% 中文：新增损失项可直接写成分数间隔形式：
\begin{equation}
  \mathcal{L}_{\mathrm{FC}}^{i}
  =\log\!\left(1+\sum_{c\in\mathcal{S}_i}
  \exp[-\mu_\theta(q_i,c)/\tau_f]\right).
  \label{eq:margin_loss}
\end{equation}
Candidates with smaller or negative margins consequently exert greater optimization pressure, while \(\lambda_f\) calibrates this targeted signal against the initial retriever's training objective. Training uses only global representations; token-level local interaction and CTRD are not part of the refinement objective.
% 中文：因此，分数间隔更小或为负的候选会产生更强的优化压力，而 \(\lambda_f\) 用于校准这一针对性信号相对于初始检索器训练目标的权重。训练仅使用全局表示；词元级局部交互和 CTRD 不属于细化目标。

\subsection{Dual-Granularity Reranking}
\label{sec:reranking_method}

Global retrieval remains responsible for searching the complete corpus. To resolve fine-grained distinctions only where they can affect the returned ranking, we optionally rescore its top-\(K\) candidates with MaxSim~\citep{ColBERT}. Let \(\{\mathbf{h}^{q}_{a}\}_{a=1}^{T_q}\) and \(\{\mathbf{h}^{c}_{b}\}_{b=1}^{T_c}\) be the token representations of a query and candidate code. Their local-interaction score is
% 中文：全局检索仍负责在完整语料库中进行搜索。为了仅在可能影响最终排名的位置解析细粒度差异，我们可选地使用 MaxSim~\citep{ColBERT} 对其前 \(K\) 个候选重新计分。设 \(\{\mathbf{h}^{q}_{a}\}_{a=1}^{T_q}\) 和 \(\{\mathbf{h}^{c}_{b}\}_{b=1}^{T_c}\) 分别为查询与候选代码的词元表示，其局部交互分数为
\begin{equation}
  s_m(q,c)=\frac{1}{T_q}\sum_{a=1}^{T_q}
  \max_{1\leq b\leq T_c}
  \cos(\mathbf{h}^{q}_{a},\mathbf{h}^{c}_{b}).
  \label{eq:maxsim}
\end{equation}

Because global and token-level scores have different query-dependent scales, each is standardized over the same top-\(K\) set. The final score is
% 中文：由于全局分数与词元级分数具有不同且依赖查询的数值尺度，我们在同一前 \(K\) 候选集合内分别对二者进行标准化。最终分数定义为
\begin{equation}
  s_r(q,c)=\alpha\widetilde{s}_\theta(q,c)
  +(1-\alpha)\widetilde{s}_m(q,c).
  \label{eq:fusion}
\end{equation}
Only candidates inside the top-\(K\) set are reordered; all remaining corpus items preserve their global-retrieval order. This stage adds no trainable parameters and is selected independently from the training objective. It does, however, incur token-level inference cost, which we measure explicitly in Section~\ref{sec:efficiency}.
% 中文：只有前 \(K\) 集合内的候选会被重新排序，其余语料库条目保持全局检索产生的顺序。该阶段不增加可训练参数，并与训练目标独立选择；但它会带来词元级推理开销，我们在第~\ref{sec:efficiency} 节中对此进行显式测量。

\section{Experiments}
\label{sec:experiments}

Our evaluation begins with retrieval effectiveness under a matched six-language protocol. Component analyses isolate failure-calibrated refinement, candidate selection, and MaxSim reranking and identify where ranking changes occur. Additional analyses cover training-side hyperparameter sensitivity, compatibility with different encoder architectures, and the effectiveness--efficiency trade-off of top-\(K\) reranking. Paired bootstrap intervals quantify query-sampling uncertainty for the fixed checkpoints.
% 中文：我们的评测从协议一致的六语言检索效果开始。组件分析分别考察失败校准细化、候选选择和 MaxSim 重排，并定位排名变化发生的位置。其他分析涵盖训练侧超参数敏感性、与不同编码器架构的兼容性，以及前 \(K\) 重排在检索效果与推理开销之间的权衡。配对 bootstrap 区间用于衡量固定检查点上的查询采样不确定性。

\paragraph{Implementation and controlled comparisons.}
The primary setting uses a CoCoSoDa encoder~\citep{CoCoSoDa} and the UA-HN training configuration~\citep{AAAIUA} for the initial retriever. The initial retriever, \method{}-Global, and \method{}-Rerank are evaluated on identical data splits and retrieval corpora with the same metric implementation. In the candidate-selection comparison, we hold the initialization, three-epoch refinement schedule, and one-candidate-per-query budget fixed, and vary only whether the added candidate is random, statically pre-mined, or harvested from the frozen retriever's high-ranked results. This design separates the effect of model-conditioned candidate selection from that of additional optimization.
% 中文：主要设置使用 CoCoSoDa 编码器~\citep{CoCoSoDa}，并采用 UA-HN~\citep{AAAIUA} 的训练配置构建初始检索器。初始检索器、\method{}-Global 和 \method{}-Rerank 均在相同的数据划分与检索语料库上使用同一指标实现进行评测。在候选选择比较中，我们固定初始化方式、三轮细化日程以及每查询一个附加候选的预算，仅改变新增候选是随机采样、静态预挖掘，还是从冻结检索器的高排名结果中获得。该设计将模型条件化候选选择的作用与额外优化的作用区分开来。

\paragraph{Training and model selection.}
We train the initial retriever for 10 epochs with a batch size of 128, a learning rate of \(8\times10^{-6}\), and a contrastive temperature of 0.03. To construct the FC pool, we freeze the validation-selected checkpoint and perform retrieval over the training corpus. After removing the paired code snippet and any candidate that shares its URL, we retain the 32 highest-ranked candidates (\(M=32\)). During refinement, we restrict this pool to the top eight candidates (\(m=8\)) and sample one candidate per query at each update (\(r=1\)). We train the refinement stage for three epochs with a batch size of 128, a learning rate of \(5\times10^{-6}\), an FC loss weight of 0.45, and an FC temperature of 0.03. The refinement objective operates exclusively on global query--code representations; neither CTRD nor a token-level local-interaction loss is used during training.
% 中文：初始检索器训练 10 个 epoch，批量大小为 128，学习率为 \(8\times10^{-6}\)，对比学习温度为 0.03。构造 FC 候选池时，我们冻结由验证集选定的检查点，并在训练语料库上执行检索。移除配对代码片段以及与其 URL 相同的所有候选后，保留排名最高的 32 个候选（\(M=32\)）。细化阶段将候选池限制为前 8 个候选（\(m=8\)），并在每次更新时为每个查询采样 1 个候选（\(r=1\)）。细化训练进行 3 个 epoch，批量大小为 128，学习率为 \(5\times10^{-6}\)，FC 损失权重为 0.45，FC 温度为 0.03。细化目标仅作用于全局查询—代码表示；训练过程中既不使用 CTRD，也不使用词元级局部交互损失。

At inference time, \method{}-Global performs standard dual-encoder retrieval over the full corpus. The optional reranker computes a token-level MaxSim score only for the top-\(K\) candidates returned by global retrieval, without introducing additional trainable parameters. It combines the per-query standardized global score \(\widetilde{s}_g\) and MaxSim score \(\widetilde{s}_m\) as \(\alpha\widetilde{s}_g+(1-\alpha)\widetilde{s}_m\). We select \(K=20\) and \(\alpha=0.5\) by maximizing macro-averaged MRR across the six validation sets, and fix both hyperparameters before test-set evaluation. Model checkpoints are likewise selected exclusively according to validation performance. Unless otherwise stated, all locally evaluated results use random seed 123456 and are obtained on a single NVIDIA H20 GPU.
% 中文：推理时，\method{}-Global 在完整语料库上执行标准双编码器检索。可选重排器仅对全局检索返回的前 \(K\) 个候选计算无额外训练参数的词元级 MaxSim 分数。它按照 \(\alpha\widetilde{s}_g+(1-\alpha)\widetilde{s}_m\) 融合逐查询标准化后的全局分数 \(\widetilde{s}_g\) 与 MaxSim 分数 \(\widetilde{s}_m\)。我们通过最大化六个验证集上的宏平均 MRR，选择 \(K=20\) 和 \(\alpha=0.5\)，并在测试集评测前固定这两个超参数。模型检查点同样完全依据验证集表现选择。除非另有说明，所有本地评测结果均使用随机种子 123456，并在单张 NVIDIA H20 GPU 上获得。

The encoder-instantiation experiments preserve the same harvesting, refinement, and reranking design. In the GraphCodeBERT setting, data-flow-aware inputs are retained, while MaxSim is restricted to lexical tokens and excludes data-flow nodes. Encoder-specific input lengths and optimization settings are reported in Appendix~\ref{app:experimental_details}.
% 中文：编码器实例化实验保持相同的候选挖掘、细化与重排设计。在 GraphCodeBERT 设置中保留数据流感知输入，但 MaxSim 仅作用于词法词元并排除数据流节点。各编码器特定的输入长度与优化设置见附录~\ref{app:experimental_details}。

\section{Conclusion}
\label{sec:conclusion}

We presented \method{}, a failure-calibrated contrastive refinement framework that learns from high-ranked unpaired candidates exposed by a frozen initial retriever. Its central refinement stage adds a margin-sensitive failure-candidate loss to the base contrastive objective, while optional Dual-Granularity Reranking combines global and MaxSim evidence within the retrieved top-\(K\). Under a matched six-language CodeSearchNet protocol, global refinement improves macro-averaged MRR from 79.77 to 80.57, and the reranked system reaches 81.06. Candidate controls and rank-conditioned results locate the main benefit in near-top misrankings. These findings support failure-calibrated refinement on the evaluated benchmark and fixed checkpoints.
% 中文：本文提出 \method{}，一种从冻结初始检索器暴露的高排名未配对候选中学习的失败校准对比细化框架。其核心细化阶段在基础对比目标上增加对分数间隔敏感的失败候选损失；可选的双粒度重排则在检索得到的前 \(K\) 个候选内融合全局证据与 MaxSim 证据。在六语言 CodeSearchNet 的协议一致评测中，全局细化将宏平均 MRR 从 79.77 提升至 80.57，重排后的系统达到 81.06。候选对照和按排名分层的结果将主要收益定位于接近顶部的错误排序。这些结果支持失败校准细化在当前基准与固定检查点上的有效性。
\section*{Limitations}

Our evidence is limited to CodeSearchNet and one audited training seed. The paired bootstrap intervals quantify uncertainty induced by the finite test sample, but they do not capture variation across independent retraining runs. CodeSearchNet also provides only one paired code snippet per query, so some high-ranked unpaired candidates may be valid alternative implementations; the operational term \emph{failure candidate} should not be interpreted as a semantic judgment. The encoder-instantiation experiments demonstrate end-to-end compatibility, but the absence of locally evaluated initial checkpoints under the same encoder-specific settings prevents protocol-matched estimates of their refinement gains. Finally, MaxSim introduces no trainable parameters but increases inference latency through top-\(K\) token interactions.
% 中文：当前证据仅覆盖 CodeSearchNet 和一个经过审计的训练随机种子。配对 bootstrap 区间衡量有限测试样本引起的不确定性，但不能反映独立重新训练之间的变化。CodeSearchNet 每个查询也只提供一个配对代码片段，因此部分高排名未配对候选可能是有效替代实现；“失败候选”这一操作性术语不应被理解为语义判断。编码器实例化实验说明完整流程具有端到端兼容性，但由于缺少相同编码器特定设置下的本地初始检查点评测，尚不能估计协议完全匹配的细化增益。最后，MaxSim 虽不增加可训练参数，却会因前 \(K\) 候选的词元交互而增加推理延迟。

\section{Retrieval Behavior by Initial Paired-Code Rank}

The transition counts reveal behavior that is obscured by aggregate MRR. Compared with the initial retriever, \method{}-Rerank improves the rank of the gold code for 7,121 queries and worsens it for 5,741 queries. It moves the gold code to rank 1 for 2,644 queries for which it was not initially top-ranked, but demotes the gold code for 1,624 queries that were initially correct at rank 1. The overall improvement therefore reflects substantial corrections on initially misranked queries, partially offset by regressions on some initially correct rankings. A confidence-aware gating mechanism could potentially mitigate these regressions.
