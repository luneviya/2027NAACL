\begin{abstract}
Dual-encoder code search enables efficient full-corpus retrieval, but standard contrastive training need not expose the model to the high-scoring candidates that determine the paired code's rank at inference time. This mismatch is especially relevant in Retrieved-but-Mis-ranked Cases, where the paired code is already near the top but remains below one or more competing snippets. We introduce \method{} (Retriever Feedback for Code Search), a second-stage framework that freezes the initial retriever and converts its full-corpus rankings into fixed, query-specific Failure Candidate Pools. Failure-Calibrated Contrastive Refinement applies a separate contrastive loss to candidates in these pools, assigning stronger optimization pressure to smaller or negative positive--negative score margins while retaining efficient global retrieval. This training procedure yields \method{}-Global; \method{}-Rerank further applies Dual-Granularity Reranking within the retrieved top-\(K\) by fusing global and token-level MaxSim scores. Under a matched six-language CodeSearchNet protocol, \method{}-Global raises macro MRR from 79.8 to 80.6, and \method{}-Rerank reaches 81.1. Budget-matched controls favor retriever-harvested candidates over random and static alternatives, while rank-conditioned analysis locates the largest gains at initial ranks 2--10.
% 中文：双编码器代码搜索能够实现高效的全库检索，但标准对比训练未必会让模型接触到那些在推理时决定配对代码排名的高分候选。这种错位在“已检索但排序错误案例”（Retrieved-but-Mis-ranked Cases）中尤其相关：配对代码已经接近顶部，却仍排在一个或多个竞争代码片段之后。本文提出 \method{}（Retriever Feedback for Code Search），一种第二阶段框架：冻结初始检索器，并将其全库排序转化为固定的、逐查询的失败候选池（Failure Candidate Pools）。失败校准对比细化（Failure-Calibrated Contrastive Refinement）对候选池中的条目计算独立的对比损失，在保留高效全局检索的同时，对正负样本分数间隔较小或为负的候选施加更强优化压力。该训练流程得到 \method{}-Global；\method{}-Rerank 进一步在检索得到的前 \(K\) 个候选内执行双粒度重排（Dual-Granularity Reranking），融合全局分数与词元级 MaxSim 分数。在六语言 CodeSearchNet 的协议一致评测中，\method{}-Global 将宏平均 MRR 从 79.8 提升至 80.6，\method{}-Rerank 达到 81.1。预算匹配的对照表明，检索器挖掘候选优于随机和静态替代方案；按排名分层的分析将最大收益定位于初始第 2--10 名。
\end{abstract}

\section{Introduction}
\label{sec:introduction}

Code search maps natural-language intent to executable implementations and supports program comprehension and reuse~\citep{CodeSearchSurvey}. Many neural code-search systems use a dual-encoder architecture: they encode queries and code independently, then rank the corpus by similarity in a shared representation space~\citep{CodeBERT,GraphCodeBERT,UniXcoder}. This dual-encoder design enables efficient full-corpus retrieval, while contrastive pre-training and fine-tuning align paired queries and code~\citep{CodeRetriever,CoCoSoDa}.
% 中文：代码搜索将自然语言意图映射到可执行实现，并为程序理解与复用提供支持~\citep{CodeSearchSurvey}。许多神经代码搜索系统采用双编码器架构：它们分别编码查询与代码，再根据共享表示空间中的相似度对语料库进行排序~\citep{CodeBERT,GraphCodeBERT,UniXcoder}。这种双编码器设计支持高效的全库检索，对比式预训练与微调则对齐配对查询和代码~\citep{CodeRetriever,CoCoSoDa}。

The effectiveness of contrastive training depends on the examples that define its competing set. Standard objectives draw negatives from the current minibatch, random sampling, or static pools formed without the trained retriever's full-corpus rankings. At inference time, however, a paired code snippet is displaced only by corpus items assigned an equal or higher score. Figure~\ref{fig:problem_setting} illustrates a Retrieved-but-Mis-ranked Case: the paired code is already near the top, yet one or more high-scoring alternatives remain above it. This supervision mismatch motivates using the frozen initial retriever's own rankings as feedback for a separate refinement stage.
% 中文：对比训练的效果取决于哪些样本构成其竞争集合。标准目标从当前小批量、随机采样或静态候选池中获取负例，而这些候选池并未利用训练完成的检索器所产生的全库排序。推理时，只有得分不低于配对代码的语料项才会使其排名后移。图~\ref{fig:problem_setting} 展示了一个“已检索但排序错误案例”（Retrieved-but-Mis-ranked Case）：配对代码已经接近顶部，却仍有一个或多个高分替代候选排在它之前。这一监督错位促使我们将冻结初始检索器自身的排序作为独立细化阶段的反馈信号。

We therefore propose \method{} (Retriever Feedback for Code Search), a three-stage framework driven by the fixed rankings of a trained retriever. \textbf{Failure Candidate Harvesting} excludes the paired example and same-URL candidates, then converts the remaining high-ranked results into a query-specific \textbf{Failure Candidate Pool}. \textbf{Failure-Calibrated Contrastive Refinement} applies a separately weighted contrastive loss to that pool while preserving the base objective. Its positive--negative score-margin form gives candidates with smaller or negative margins greater optimization pressure. These two stages produce \method{}-Global, which retains full-corpus dual-encoder retrieval. \method{}-Rerank enables \textbf{Dual-Granularity Reranking}, which computes token-level MaxSim scores and combines them with global retrieval scores through Global--Local Score Fusion within the retrieved top-\(K\).
% 中文：为此，我们提出 \method{}（Retriever Feedback for Code Search），一种由训练完成的检索器固定排序驱动的三阶段框架。\textbf{失败候选挖掘（Failure Candidate Harvesting）}排除配对样本和同 URL 候选，再将其余高排名结果转化为逐查询的\textbf{失败候选池（Failure Candidate Pool）}。\textbf{失败校准对比细化（Failure-Calibrated Contrastive Refinement）}保留基础目标，并对该候选池计算单独加权的对比损失。其正负样本分数间隔形式使间隔较小或为负的候选产生更强优化压力。这两个阶段得到保留全库双编码器检索的 \method{}-Global。\method{}-Rerank 启用\textbf{双粒度重排（Dual-Granularity Reranking）}：它在检索得到的前 \(K\) 个候选内计算词元级 MaxSim 分数，并通过全局—局部分数融合（Global--Local Score Fusion）将其与全局检索分数结合。

In a protocol-matched local evaluation across all six CodeSearchNet languages~\citep{CodeSearchNet}, \method{}-Global raises macro MRR from 79.8 to 80.6 and R@1 from 70.7 to 71.9; \method{}-Rerank reaches 81.1 MRR and 72.6 R@1. Controlled comparisons favor retriever-mined Failure Candidates over random and static alternatives, with the largest gains concentrated in near-top misrankings (initial ranks 2--10).
% 中文：在覆盖全部六种 CodeSearchNet 语言~\citep{CodeSearchNet}的协议一致本地评测中，\method{}-Global 将宏平均 MRR 从 79.8 提升至 80.6，并将 R@1 从 70.7 提升至 71.9；\method{}-Rerank 达到 81.1 MRR 和 72.6 R@1。受控比较表明，检索器挖掘的失败候选优于随机和静态替代方案，且最大收益集中在接近顶部的排序错误案例中，即配对代码的初始排名为第 2--10 位时。

\section{Related Work}
\label{sec:related_work}

\subsection{Code Search}

\paragraph{Pre-trained code representations.}
Code search progressed from lexical, structural, and API-aware matching~\citep{Sourcerer,Portfolio,CodeHow} to neural systems that learn shared query--code representations~\citep{DeepCS,UNIF}. Subsequent work incorporated token overlap, program structure, contextual translation, relevance matching, and cross-domain adaptation~\citep{OCoR,TabCS,TranCS,CSRS,CDCS}. Pre-trained models further strengthened these representations: CodeBERT learns from bimodal code--text context, GraphCodeBERT injects data flow, and UniXcoder unifies cross-modal pre-training~\citep{CodeBERT,GraphCodeBERT,UniXcoder}; PLBART and CodeT5 extend pre-training across understanding and generation tasks~\citep{PLBART,CodeT5}, while UniCoR targets cross-language retrieval~\citep{UniCoR}. When adapted as dual encoders for code search, pre-trained code models use precomputed code representations to retrieve efficiently over the full corpus.
% 中文：代码搜索从基于词法、结构和 API 感知的匹配方法~\citep{Sourcerer,Portfolio,CodeHow}，发展到学习共享查询—代码表示的神经系统~\citep{DeepCS,UNIF}。后续工作进一步融合词元重叠、程序结构、上下文翻译、相关性匹配和跨领域适配~\citep{OCoR,TabCS,TranCS,CSRS,CDCS}。预训练模型进一步强化了这些表示：CodeBERT 从代码—文本双模态上下文中学习，GraphCodeBERT 注入数据流信息，UniXcoder 统一跨模态预训练~\citep{CodeBERT,GraphCodeBERT,UniXcoder}；PLBART 与 CodeT5 将预训练扩展到理解和生成任务~\citep{PLBART,CodeT5}，UniCoR 则面向跨语言检索~\citep{UniCoR}。这些模型通过预计算代码表示来支持高效的全库搜索。

\paragraph{Contrastive code retrieval.}
Contrastive code retrieval learns a shared retrieval space by pulling matched query--code representations together and separating unmatched candidates. SynCoBERT introduces syntax-guided multimodal contrastive objectives, CodeRetriever combines unimodal and bimodal contrastive pre-training, and CoCoSoDa couples soft data augmentation with momentum encoders to produce more consistent negative representations~\citep{SynCoBERT,CodeRetriever,CoCoSoDa}. Corder and ContraCode construct contrastive views through semantics-preserving code transformations, while ContraBERT further adapts pre-trained code models through contrastive learning~\citep{Corder,ContraCode,ContraBERT}.
% 中文：对比式方法通过语法引导的多模态学习、大规模配对预训练、动量编码器、语义保持变换和增强视图来强化代码—文本对齐~\citep{SynCoBERT,CodeRetriever,CoCoSoDa,Corder,ContraCode,ContraBERT}。这些目标改进初始训练阶段学习到的表示。

\paragraph{Negative-aware training.}
Negative-aware objectives further change how contrastive competitors are selected or weighted. Soft-InfoNCE assigns different weights to negative pairs according to estimated potential relevance~\citep{SoftInfoNCE}; uncertainty-aware training combines hard-negative sampling with uncertainty representations of queries and code~\citep{AAAIUA}; and HedgeCode introduces code--text relevance detection as auxiliary supervision in multi-task training~\citep{HedgeCode}. CoCoHaNeRe incorporates hard negatives similar to the paired code into contrastive training, whereas R2PS samples hard negatives from the rankings of a trained dual encoder to train a downstream cross-encoder~\citep{CoCoHaNeRe,R2PS}. However, these methods do not use feedback from the initial retriever to further optimize the retriever itself. \method{} instead introduces this feedback mechanism: it converts high-ranked unpaired candidates into fixed Failure Candidate Pools and uses them for failure-calibrated refinement of the retriever.
% 中文：负样本感知目标进一步改变对比竞争项的选择或加权方式。Soft-InfoNCE 根据估计的潜在相关性为负样本对赋予不同权重~\citep{SoftInfoNCE}；不确定性感知训练将困难负例采样与查询和代码的不确定性表示相结合~\citep{AAAIUA}；HedgeCode 将代码—文本相关性检测作为多任务训练中的辅助监督~\citep{HedgeCode}。CoCoHaNeRe 将与配对代码相似的困难负例纳入对比训练，而 R2PS 从已训练双编码器的排序中采样困难负例，用于训练下游交叉编码器~\citep{CoCoHaNeRe,R2PS}。然而，这些方法并未利用初始检索器的反馈来进一步优化检索器本身。\method{} 则引入这一反馈机制：它将高排名未配对候选转化为固定的失败候选池，并将其用于对检索器进行失败校准细化。

\subsection{Retriever Feedback and Refinement}

Hard-negative mining in dense text retrieval has used several strategies to obtain more targeted supervision from retrieval results. DPR uses high-ranked BM25 passages as hard negatives, ANCE retrieves corpus-wide negatives from an asynchronously updated approximate-nearest-neighbor index, HardNegDR studies static and dynamic hard-negative training, and RocketQA combines cross-batch negatives with denoised hard negatives~\citep{DPR,ANCE,HardNegDR,RocketQA}. These studies show that retrieval results can expose more targeted competitors than random negatives. Building on this observation, \method{} exploits these competitors through an offline, decoupled feedback process: the frozen initial retriever produces a full-corpus ranking once for each query, and its high-ranked unpaired candidates form a fixed Failure Candidate Pool for subsequent refinement.
% 中文：在稠密文本检索中，困难负例挖掘通过检索负例、索引刷新、大规模候选池和去噪获得监督~\citep{DPR,ANCE,HardNegDR,RocketQA}。本文使用\emph{检索器反馈（retriever feedback）}指代冻结初始检索器离线产生的全库排序。\method{} 在初始训练完成后获取这一信号，将逐查询的高排名未配对候选转化为固定的失败候选池，并在独立的细化阶段使用该候选池，由此将候选发现与参数更新分开。表~\ref{tab:main_results} 将 \method{} 行归入检索器反馈类别，并置于协议一致的本地评测区块中，以承接从预训练表示、对比式检索到负样本感知训练的演进。\emph{失败候选（Failure Candidate）}是高排名未配对竞争项的操作性标签；其语义有效性无法由基准配对关系确定。

\subsection{Late Interaction and Reranking}

Fine-grained code-search methods use co-attention and cross-modal features to capture local query--code correspondences~\citep{FcarCS,FineGrainedCS}; HedgeCode models fine-grained code--text differences through relevance detection and multi-task contrastive learning~\citep{HedgeCode}. Late interaction retains token-level representations and aggregates token-wise similarities at scoring time; ColBERT's MaxSim is representative~\citep{ColBERT}. \method{}-Rerank retains \method{}-Global for full-corpus retrieval, applies MaxSim only to its retrieved top-\(K\), and then fuses sequence-level global scores with token-level matching evidence.
% 中文：细粒度代码搜索模型利用协同注意力与跨模态特征区分高度相近的代码片段~\citep{FcarCS,FineGrainedCS,HedgeCode}。后期交互保留词元表示并聚合逐词元相似度，ColBERT 的 MaxSim 是代表性形式~\citep{ColBERT}。\method{} 在训练与全库检索中保留全局表示，并在启用双粒度重排时对检索得到的前 \(K\) 个候选应用 MaxSim。全局—局部分数融合在不增加可训练参数的情况下组合标准化分数，同时带来可测量的推理开销。

\section{Method}
\label{sec:method}

\method{} is a retrieval-feedback framework that turns the corpus-wide rankings produced by a trained dual encoder into targeted supervision for refining its retrieval space. As shown in Figure~\ref{fig:framework}, Failure Candidate Harvesting uses a frozen initial retriever to organize each query's highest-ranked unpaired competitors into a query-specific pool, and Failure-Calibrated Contrastive Refinement concentrates learning on the score comparisons exposed by the initial ranking. The resulting \method{}-Global is a refined dual encoder for full-corpus retrieval. \method{}-Rerank further determines the final top-\(K\) ordering by combining sequence-level global scores with token-level MaxSim evidence.
% 中文：\method{} 是一种检索器反馈框架，它将训练完成的双编码器产生的全语料库排序转化为细化检索空间的针对性监督。如图~\ref{fig:framework} 所示，失败候选挖掘利用冻结的初始检索器，将每个查询排名最高的未配对竞争候选组织为逐查询候选池；失败校准对比细化则聚焦于初始排序所暴露的分数比较。由此得到的 \method{}-Global 是用于全语料库检索的细化双编码器。\method{}-Rerank 进一步融合序列级全局分数与词元级 MaxSim 证据，确定前 \(K\) 个候选的最终次序。

\subsection{Problem Formulation}
\label{sec:problem_formulation}

Let \(\mathcal{D}=\{(q_i,c_i^+)\}_{i=1}^{N}\) denote a code-search training set, where \(q_i\) is a natural-language query and \(c_i^+\) is its paired code snippet. A dual encoder maps queries and code into a shared space through \(f_\theta\) and \(g_\theta\). Let \(f_\theta(q)\) and \(g_\theta(c)\) denote the resulting \(\ell_2\)-normalized sequence representations. Their global retrieval score is
% 中文：设 \(\mathcal{D}=\{(q_i,c_i^+)\}_{i=1}^{N}\) 表示代码搜索训练集，其中 \(q_i\) 是自然语言查询，\(c_i^+\) 是与之配对的代码片段。双编码器分别通过 \(f_\theta\) 和 \(g_\theta\) 将查询与代码映射到共享空间。令 \(f_\theta(q)\) 和 \(g_\theta(c)\) 表示所得的 \(\ell_2\) 归一化序列表示，其全局检索分数定义为
\begin{equation}
  s_\theta(q,c)=f_\theta(q)^{\top}g_\theta(c).
  \label{eq:global_score}
\end{equation}
Because both representations have unit norm, \(s_\theta\) is their cosine similarity, and candidates are ranked in descending order of this score.
% 中文：由于两个表示均具有单位范数，\(s_\theta\) 等于二者的余弦相似度，候选代码按照该分数从高到低排序。

For a competing candidate \(c^-\), define the score margin as
% 中文：对于竞争候选 \(c^-\)，分数间隔定义为
\begin{equation}
  \mu_\theta(q_i,c^-)
  =s_\theta(q_i,c_i^+)-s_\theta(q_i,c^-).
  \label{eq:score_margin}
\end{equation}
The rank of the paired code can then be written as
% 中文：配对代码的排名可写为
\begin{equation}
  \operatorname{rank}_\theta(c_i^+\mid q_i)
  =1+\sum_{c\in\mathcal{C}\setminus\{c_i^+\}}
  \mathbb{I}\!\left[\mu_\theta(q_i,c)\leq 0\right],
  \label{eq:rank_margin}
\end{equation}
where \(\mathcal{C}\) is the retrieval corpus; Equation~\ref{eq:rank_margin} counts a tied candidate before the paired code. A negative margin identifies a candidate that already outranks the paired code, whereas a positive margin \(\mu_\theta(q_i,c)\) is the exact score gap separating the pair. Candidates with nonpositive or small positive margins therefore lie at or near the observed ranking boundary, while large-margin candidates are already well separated. The negative sets used to train the initial retriever are constructed without access to the final checkpoint's query-specific full-corpus rankings. \method{} uses these rankings as feedback to refine the comparisons that determine the paired code's observed ranks.
% 中文：其中 \(\mathcal{C}\) 表示检索语料库；式~\ref{eq:rank_margin} 将同分候选计在配对代码之前。负间隔表示候选已经排在配对代码之前，正间隔 \(\mu_\theta(q_i,c)\) 则精确表示二者之间的分数差。因此，间隔非正或较小的候选位于观测排序边界上或其附近，而大间隔候选已经与配对代码充分分开。初始检索器的负例集合在构造时无法使用最终检查点的逐查询全语料库排序。\method{} 将这些排序作为反馈，用于细化决定配对代码观测排名的分数比较。

Competitors are query dependent: a code snippet may rank low for one query yet highly for another. Refinement therefore associates each query with candidates from its own corpus ranking, preserving the link between observed scores and subsequent contrastive comparisons.
% 中文：竞争候选依赖于具体查询：同一代码片段在一个查询下可能排名较低，却可能在另一个查询下排名很高。因此，细化为每个查询关联其自身语料库排序中的候选，从而保留观测分数与后续对比比较之间的对应关系。

\subsection{Failure Candidate Harvesting}
\label{sec:failure_harvesting}

We first train an initial retriever with the underlying contrastive code-search objective and freeze its parameters \(\theta_0\). For every training query, the frozen model retrieves from the training code corpus. Let \(\mathcal{E}_i\) contain the paired code and all candidates sharing its URL. We remove \(\mathcal{E}_i\) and retain the \(M\) highest-scoring candidates:
% 中文：我们首先使用基础对比式代码搜索目标训练初始检索器，并冻结其参数 \(\theta_0\)。对于每个训练查询，冻结模型在训练代码语料库中执行检索。令 \(\mathcal{E}_i\) 包含配对代码以及与其共享 URL 的所有候选；移除 \(\mathcal{E}_i\) 后，保留得分最高的 \(M\) 个候选：
\begin{equation}
  \begin{aligned}
    \mathcal{H}_i
    &=\operatorname{Top}_{M}^{s_{\theta_0}(q_i,\cdot)}
      (\mathcal{C}_{\mathrm{train}}\setminus\mathcal{E}_i), \\
    \mathcal{F}_i
    &=\operatorname{Top}_{m}^{s_{\theta_0}(q_i,\cdot)}(\mathcal{H}_i).
  \end{aligned}
  \label{eq:fc_pool}
\end{equation}

We call \(\mathcal{F}_i\) the \emph{Failure Candidate Pool} for \(q_i\), and its members \emph{Failure Candidates}. With \(1\leq m\leq M\), \(M\) sets the size of the cached corpus-retrieval pool, while \(m\) selects its highest-ranked prefix for refinement. This prefix contains the strongest unpaired competitors observed for \(q_i\). At each update, we sample \(r\) rank positions uniformly without replacement from the eligible prefix, which fixes the added comparison budget.
% 中文：我们将 \(\mathcal{F}_i\) 称为查询 \(q_i\) 的\emph{失败候选池（Failure Candidate Pool）}，并将其中元素称为\emph{失败候选（Failure Candidates）}。在 \(1\leq m\leq M\) 时，\(M\) 决定全语料库检索所得缓存池的规模，\(m\) 则选取其中排名最高的前缀用于细化。该前缀包含初始检索器针对 \(q_i\) 观测到的最强未配对竞争候选。每次更新从可用前缀的排名位置中均匀、无放回地采样 \(r\) 个位置，从而固定新增比较的预算。

Harvesting runs once with the frozen parameters \(\theta_0\). Pool membership and initial order consequently remain fixed while refinement updates \(\theta\), so the optimization uses a stable record of the initial retriever's ranking behavior without rerunning corpus retrieval after every update.
% 中文：候选挖掘仅使用冻结参数 \(\theta_0\) 执行一次。因此，在细化更新 \(\theta\) 的过程中，候选池成员及其初始次序保持不变；优化过程据此使用初始检索器排序行为的固定记录，而无须在每次更新后重新执行全语料库检索。

\subsection{Failure-Calibrated Contrastive Refinement}
\label{sec:failure_refinement}

Starting from \(\theta_0\), we retain the initial retriever's contrastive objective \(\mathcal{L}_{\mathrm{base}}\) and add a contrastive softmax over the paired code and harvested competitors. For a minibatch \(\mathcal{B}\), let \(\mathcal{S}_i\subseteq\mathcal{F}_i\) contain the \(r\) candidates sampled for query \(q_i\), and let \(\tau_f>0\) denote the failure-candidate temperature. The failure-candidate loss is
% 中文：以 \(\theta_0\) 为起点，我们保留初始检索器的对比目标 \(\mathcal{L}_{\mathrm{base}}\)，并在配对代码与挖掘得到的竞争候选上加入对比 softmax。对于小批量 \(\mathcal{B}\)，设 \(\mathcal{S}_i\subseteq\mathcal{F}_i\) 包含为查询 \(q_i\) 采样的 \(r\) 个候选，并令 \(\tau_f>0\) 表示失败候选温度。失败候选损失定义为
\begin{equation}
  \mathcal{L}_{\mathrm{FC}}^{i}
  =-\log
  \frac{\exp(s_\theta(q_i,c_i^+)/\tau_f)}
  {\begin{aligned}
     &\exp(s_\theta(q_i,c_i^+)/\tau_f) \\
     &\quad+\sum_{c\in\mathcal{S}_i}
       \exp(s_\theta(q_i,c)/\tau_f)
   \end{aligned}},
  \label{eq:fc_loss}
\end{equation}
and the complete refinement objective is
% 中文：完整的细化目标为
\begin{equation}
  \mathcal{L}_{\mathrm{ref}}
  =\mathcal{L}_{\mathrm{base}}
  +\frac{\lambda_f}{|\mathcal{B}|}
   \sum_{i\in\mathcal{B}}\mathcal{L}_{\mathrm{FC}}^{i}.
  \label{eq:refinement_loss}
\end{equation}

Equation~\ref{eq:refinement_loss} adds \(\mathcal{L}_{\mathrm{FC}}\) as a separately weighted term without changing the definition of \(\mathcal{L}_{\mathrm{base}}\). The coefficient \(\lambda_f\) controls the relative contribution of the added failure-candidate objective.
% 中文：式~\ref{eq:refinement_loss} 将 \(\mathcal{L}_{\mathrm{FC}}\) 作为独立加权项加入，同时不改变 \(\mathcal{L}_{\mathrm{base}}\) 的定义。系数 \(\lambda_f\) 控制新增失败候选目标的相对贡献。

\paragraph{Score-margin interpretation.}
The added term admits a direct score-margin form,
% 中文：新增损失项可直接写成分数间隔形式：
\begin{equation}
  \mathcal{L}_{\mathrm{FC}}^{i}
  =\log\!\left(1+\sum_{c\in\mathcal{S}_i}
  \exp[-\mu_\theta(q_i,c)/\tau_f]\right).
  \label{eq:margin_loss}
\end{equation}
For candidates in the same sampled set, the gradient magnitude with respect to \(\mu_\theta(q_i,c)\) is proportional to \(\exp[-\mu_\theta(q_i,c)/\tau_f]\). Smaller or negative margins therefore receive greater optimization pressure, and \(\tau_f\) controls how sharply that pressure concentrates as the margin decreases. This margin-dependent weighting defines failure-calibrated refinement, whereas \(\lambda_f\) balances the aggregate FC objective against \(\mathcal{L}_{\mathrm{base}}\). Together, the two objectives refine the global retrieval space to produce \method{}-Global.
% 中文：对于同一采样集合中的候选，损失关于 \(\mu_\theta(q_i,c)\) 的梯度幅度与 \(\exp[-\mu_\theta(q_i,c)/\tau_f]\) 成正比。因此，间隔较小或为负的候选承受更强的优化压力，而 \(\tau_f\) 控制该压力随间隔减小而集中的程度。这种依赖分数间隔的加权构成失败校准细化；\(\lambda_f\) 则平衡整体 FC 目标与 \(\mathcal{L}_{\mathrm{base}}\) 的相对权重。两个目标共同细化全局检索空间，得到 \method{}-Global。

\subsection{Dual-Granularity Reranking}
\label{sec:reranking_method}

The rank-margin formulation above motivates concentrating additional comparison on high-scoring competitors. The same rank-focused principle carries into inference: \method{}-Global first retrieves candidates from the full corpus with sequence-level scores, and \method{}-Rerank then applies token-level MaxSim only to the resulting top-\(K\)~\citep{ColBERT}. The fused global and local scores determine the final order within this shortlist.
% 中文：上述分数间隔形式说明，应当将额外的比较集中于高分竞争候选。同一面向排名的原则也延伸到推理阶段：\method{}-Global 首先根据序列级分数从完整语料库中检索候选，\method{}-Rerank 随后仅对所得的前 \(K\) 个候选应用词元级 MaxSim~\citep{ColBERT}。融合后的全局分数与局部分数决定该候选列表内部的最终次序。

Let \(\{\mathbf{h}^{q}_{a}\}_{a=1}^{T_q}\) and \(\{\mathbf{h}^{c}_{b}\}_{b=1}^{T_c}\) be the contextual representations of the valid query tokens and lexical code tokens, respectively; padding and special tokens are excluded. Their local-interaction score is then defined as
% 中文：设 \(\{\mathbf{h}^{q}_{a}\}_{a=1}^{T_q}\) 和 \(\{\mathbf{h}^{c}_{b}\}_{b=1}^{T_c}\) 分别为有效查询词元与词法代码词元的上下文表示，并排除填充词元与特殊词元。其局部交互分数随后定义为
\begin{equation}
  s_{\mathrm{loc}}(q,c)=\frac{1}{T_q}\sum_{a=1}^{T_q}
  \max_{1\leq b\leq T_c}
  \cos(\mathbf{h}^{q}_{a},\mathbf{h}^{c}_{b}).
  \label{eq:maxsim}
\end{equation}

For each query token, the maximum selects the code token with the highest cosine similarity; averaging these maxima aggregates the token-level matches while normalizing for query length.
% 中文：对于每个查询词元，最大值操作选出余弦相似度最高的代码词元；对这些最大值取平均，在聚合词元级匹配证据的同时对查询长度进行归一化。

Let \(\mathcal{R}_K(q)\) be the top-\(K\) set returned by \method{}-Global. For \(x\in\{\theta,\mathrm{loc}\}\), let \(\bar{s}_x(q)\) and \(\sigma_x(q)\) be the mean and population standard deviation of \(s_x(q,\cdot)\) over \(\mathcal{R}_K(q)\). We standardize each score within the query-specific set as
% 中文：令 \(\mathcal{R}_K(q)\) 表示 \method{}-Global 返回的前 \(K\) 个候选集合。对于 \(x\in\{\theta,\mathrm{loc}\}\)，令 \(\bar{s}_x(q)\) 和 \(\sigma_x(q)\) 分别表示 \(s_x(q,\cdot)\) 在 \(\mathcal{R}_K(q)\) 上的均值与总体标准差。每类分数在该逐查询候选集合内标准化为
\begin{equation}
  \widetilde{s}_x(q,c)
  =\frac{s_x(q,c)-\bar{s}_x(q)}{\sigma_x(q)+10^{-6}},
  \qquad x\in\{\theta,\mathrm{loc}\}.
  \label{eq:score_standardization}
\end{equation}
With \(\alpha\in[0,1]\), the final score is
% 中文：取 \(\alpha\in[0,1]\)，最终分数定义为
\begin{equation}
  s_r(q,c)=\alpha\widetilde{s}_\theta(q,c)
  +(1-\alpha)\widetilde{s}_{\mathrm{loc}}(q,c).
  \label{eq:fusion}
\end{equation}
Only candidates inside the top-\(K\) set are reordered; all remaining corpus items preserve their \method{}-Global order.
% 中文：只有前 \(K\) 集合内的候选会被重新排序，其余语料库条目保持 \method{}-Global 产生的顺序。

\section{Experiments}
\label{sec:experiments}

We evaluate \method{} under protocol-matched full-corpus retrieval on all six CodeSearchNet languages. The experiments separate failure-calibrated refinement from MaxSim reranking, compare retriever-mined Failure Candidates with budget-matched alternatives, and locate the gains by the paired code's initial rank. We then examine reranking across encoder architectures and measure the effectiveness--latency trade-off of \method{}-Rerank. Paired-bootstrap intervals quantify test-query sampling uncertainty for fixed checkpoints.
% 中文：我们在六种 CodeSearchNet 语言的协议一致全语料库检索设置下评估 \method{}。实验分别考察失败校准细化与 MaxSim 重排，比较检索器挖掘的失败候选与候选预算一致的替代方案，并依据配对代码的初始排名定位收益。随后，我们考察重排在不同编码器架构上的表现，并测量 \method{}-Rerank 的效果--延迟权衡。配对 bootstrap 区间衡量固定检查点下的测试查询采样不确定性。

Appendix~\ref{app:experimental_details} provides complete optimization and encoder-specific settings, together with provenance checks and validation-selection details.

\paragraph{Reranking and encoder settings.}
\method{}-Global performs full-corpus dual-encoder retrieval. \method{}-Rerank computes MaxSim only for the retrieved top-\(K\) and combines the per-query standardized global and token-level scores as \(\alpha\widetilde{s}_\theta+(1-\alpha)\widetilde{s}_{\mathrm{loc}}\). We select \(K=20\) and \(\alpha=0.5\) using unrounded six-language macro validation MRR and fix these values, together with all model checkpoints, before test evaluation.
% 中文：\method{}-Global 执行全库双编码器检索。\method{}-Rerank 仅对检索得到的前 \(K\) 个候选计算 MaxSim，并按照 \(\alpha\widetilde{s}_\theta+(1-\alpha)\widetilde{s}_{\mathrm{loc}}\) 融合逐查询标准化后的全局分数与词元级分数。我们依据未舍入的六语言宏平均验证集 MRR 选定 \(K=20\) 和 \(\alpha=0.5\)，并在测试集评测前固定这两个取值及全部模型检查点。

The encoder-instantiation experiments preserve the same harvesting, refinement, and reranking design. GraphCodeBERT retains data-flow-aware inputs, while its MaxSim score uses lexical tokens and excludes data-flow nodes.
% 中文：编码器实例化实验保持相同的候选挖掘、细化与重排设计。GraphCodeBERT 保留数据流感知输入，其 MaxSim 分数使用词法词元并排除数据流节点。

\paragraph{Statistical comparisons.}
We estimate 95\% confidence intervals for paired MRR differences using 10,000 repetitions of a language-stratified paired bootstrap. Within each language, test queries are resampled with replacement, and each sampled query contributes the reciprocal-rank difference between the same two systems. The six language-level differences are then macro-averaged. Because the model checkpoints remain fixed, these intervals quantify uncertainty from the finite test queries rather than variation across retraining runs. We compute intervals only for \method{}-Global and \method{}-Rerank against the protocol-matched initial retriever; cited prior-work rows are excluded.
% 中文：我们采用按语言分层的配对 bootstrap 进行 10,000 次重复采样，为 MRR 配对差值估计 95\% 置信区间。在每种语言内部，对测试查询进行有放回重采样；每个被采样查询贡献同一对系统之间的倒数排名差。随后对六种语言的差值进行宏平均。由于模型检查点保持固定，这些区间衡量有限测试查询带来的不确定性，而不是不同重新训练运行之间的变化。置信区间仅用于比较 \method{}-Global、\method{}-Rerank 与协议一致的初始检索器，不包含引用的既有工作结果。

\subsection{Overall Retrieval Effectiveness}
\label{sec:main_results}

Under the shared evaluation protocol in Table~\ref{tab:main_results}, \method{}-Global raises macro MRR from 79.8 to 80.6, and validation-selected MaxSim reranking further raises it to 81.1. These results correspond to absolute gains of 0.8 points for \method{}-Global and 1.3 points for \method{}-Rerank. The improvement holds across all six languages, ranging from 0.6 to 1.2 points for \method{}-Global and from 1.0 to 1.7 points for \method{}-Rerank.
% 中文：在表~\ref{tab:main_results} 的统一评测协议下，\method{}-Global 将宏平均 MRR 从 79.8 提升至 80.6，验证集选定的 MaxSim 重排进一步将其提高到 81.1。对应地，\method{}-Global 和 \method{}-Rerank 的绝对增益分别为 0.8 和 1.3 个点。六种语言均获得提升：\method{}-Global 的增益为 0.6--1.2 个点，\method{}-Rerank 的增益为 1.0--1.7 个点。

The gains are concentrated near the top of the ranked list: from the initial retriever to \method{}-Rerank, R@1 increases from 70.7 to 72.6 and R@5 from 91.3 to 91.7, while R@10 remains 95.1 at the displayed precision. Together with the rank-stratified results in Table~\ref{tab:rank_strata}, this pattern indicates that \method{} primarily improves paired-code rankings near the top.
% 中文：收益主要集中在排序列表顶部附近：从初始检索器到 \method{}-Rerank，R@1 从 70.7 提升至 72.6，R@5 从 91.3 提升至 91.7，而 R@10 在当前显示精度下保持 95.1。结合表~\ref{tab:rank_strata} 的初始排名分组结果，这一模式表明 \method{} 主要改善配对代码在顶部附近的排名。

\paragraph{Refinement and reranking both improve MRR.}
Table~\ref{tab:ablation} isolates failure-calibrated refinement and MaxSim reranking under the shared \(K=20\), \(\alpha=0.5\) configuration. \section{Conclusion}
\label{sec:conclusion}

We presented \method{}, which uses the full-corpus rankings of an initial dual encoder to target refinement at the high-scoring competitors that determine retrieval order. Failure Candidate Harvesting and Failure-Calibrated Contrastive Refinement convert these rankings into query-specific supervision, producing \method{}-Global; \method{}-Rerank further incorporates token-level MaxSim evidence within the retrieved top-\(K\). Under a matched six-language CodeSearchNet protocol, \method{}-Global raises macro MRR from 79.8 to 80.6, and \method{}-Rerank reaches 81.1. Budget-matched controls favor retriever-harvested candidates over random and static alternatives, with the largest gains concentrated on queries whose paired code initially ranks 2--10. Retriever feedback targets near-top misrankings.
% 中文：本文提出 \method{}，利用初始双编码器的全语料库排序，针对决定检索次序的高分竞争候选开展细化。失败候选挖掘与失败校准对比细化将这些排序转化为逐查询监督，得到 \method{}-Global；\method{}-Rerank 则在检索得到的前 \(K\) 个候选内进一步融合词元级 MaxSim 证据。在六语言 CodeSearchNet 的协议一致评测中，\method{}-Global 将宏平均 MRR 从 79.8 提升至 80.6，\method{}-Rerank 达到 81.1。预算匹配的对照结果支持检索器挖掘候选优于随机和静态替代方案，且最大收益集中在配对代码初始排名第 2--10 位的查询上。检索器反馈针对接近顶部的排序错误。

\newpage
\section*{Limitations}

\method{} has three main limitations. First, refinement supervision is derived from a fixed full-corpus ranking, so each Failure Candidate Pool reflects the initial retriever rather than later refinement states. Future work can examine when selective pool refresh is beneficial. Second, the current evaluation covers the six-language CodeSearchNet benchmark, whose single-pair annotation also defines candidate supervision. High-ranked unpaired candidates may therefore include valid alternative implementations; multi-positive or semantic-equivalence supervision could distinguish these cases. The reported bootstrap intervals characterize test-query uncertainty for fixed checkpoints, while repeated runs are required to estimate training variability. Third, \method{}-Rerank can reorder only the top-\(K\) candidates returned by \method{}-Global. Increasing \(K\) expands this set but raises token-level rescoring latency, motivating further study of adaptive depths and more efficient late-interaction scoring.
% 中文：\method{} 主要有三点局限。首先，细化监督来自一次固定的全语料库排序，因此每个失败候选池反映的是初始检索器，而不是后续细化状态。未来可以研究在什么条件下选择性刷新候选池能够带来收益。其次，当前评测覆盖六语言 CodeSearchNet 基准，而该基准的单配对标注也决定了候选监督。高排名未配对候选因此可能包含有效的替代实现；多正例或语义等价监督可以进一步区分这些情况。当前 bootstrap 区间衡量固定检查点下的测试查询不确定性，而估计训练波动仍需要重复运行。第三，\method{}-Rerank 只能重新排列 \method{}-Global 返回的前 \(K\) 个候选。增大 \(K\) 可以扩大这一集合，但也会增加词元级重新计分延迟，这促使未来进一步研究自适应深度和更高效的后期交互计分。
