\title{\method{}: Learning from Retriever-Induced Confusions for Code Search}

% Keep the submission anonymous while using the review option.

\begin{abstract}
Neural code search systems commonly optimize static hard negatives that need not match the high-ranked confusions produced at inference time. We propose \method{}, a failure-calibrated refinement framework that mines high-ranked non-ground-truth candidates from a frozen retriever and uses them as targeted contrastive supervision. \method{} first refines global query--code representations and then applies a parameter-free token-level MaxSim reranker only to the top-\(K\) candidates. Under a matched local protocol on the six-language CodeSearchNet benchmark, refinement raises macro MRR from 79.8 to 80.6, and final reranking reaches 81.1, a 1.3-point paired improvement over the initial retriever with a query-level 95\% bootstrap confidence interval of [1.11, 1.47]. Candidate-selection controls and rank-stratified diagnostics show that the gains concentrate on initially mis-ranked queries, while also revealing regressions for some initial top-1 cases.
% 中文：神经代码检索系统通常使用静态困难负样本进行优化，但这些负样本未必对应模型在推理时实际产生的高排名混淆候选。本文提出 \method{}，一种失败校准的细化框架：它从冻结的检索器中挖掘高排名非标注候选，并将其作为有针对性的对比监督。\method{} 首先细化全局查询—代码表示，随后仅对前 \(K\) 个候选应用无参数的词元级 MaxSim 重排器。在六语言 CodeSearchNet 基准上的协议一致本地评测中，全局细化将宏平均 MRR 从 79.8 提升到 80.6，最终重排达到 81.1；相比初始检索器配对提高 1.3 个点，查询级 95\% bootstrap 置信区间为 [1.11, 1.47]。候选选择对照和分层排名诊断表明，收益主要集中在初始排序错误的查询上，同时也揭示了部分初始首位样本发生回退。
\end{abstract}

\section{Experiments}
\label{sec:experiments}

We evaluate three claims: (1) whether refinement with retriever-mined candidates improves code search; (2) whether the gain is specific to this candidate-selection strategy rather than to an additional training stage; and (3) where the gain occurs in the ranked list and what inference cost it incurs. We organize the experiments around these claims instead of treating each implementation component as an independent contribution.
% 中文：我们围绕三个主张展开实验：（1）使用检索器挖掘的候选进行细化，能否提升代码检索；（2）性能增益是否确实来自这种候选选择策略，而不只是增加了一个训练阶段；（3）增益发生在排序列表的哪些位置，以及需要多少推理开销。实验据此组织，而不是把每个实现模块都当作独立贡献。

\subsection{Experimental Setup}
\label{sec:experimental_setup}

\paragraph{Dataset and metrics.}
We use the standard six-language CodeSearchNet benchmark~\citep{CodeSearchNet}, which contains natural-language queries paired with code in Java, JavaScript, Ruby, Python, PHP, and Go. Table~\ref{tab:dataset_stats} reports the frozen train, validation, and test splits. For each test query, a system ranks the corresponding language-specific codebase. Mean Reciprocal Rank (MRR) is the primary metric because our method targets the order of highly ranked candidates; we additionally report Recall at ranks 1, 5, and 10 (R@1/R@5/R@10). All values are percentages.

\paragraph{Implementation and comparison protocol.}
Our implementation uses the CoCoSoDa~\citep{CoCoSoDa} encoder and follows the UA-HN~\citep{AAAIUA} training configuration. The initial retriever, \method{}-Global, and \method{} with reranking are evaluated with the same data, candidate codebase, and evaluation script. Values copied from prior papers are marked as reported and are included only to situate our results; paired differences and confidence intervals are computed only against the initial checkpoint evaluated in our pipeline. We compare candidate-selection strategies under an equal budget of one additional candidate per query: a uniformly sampled non-positive (Random), a fixed pre-mined hard negative (Static), and a high-ranked non-ground-truth candidate mined by the frozen retriever (FC).
% 中文：本文实现采用 CoCoSoDa~\citep{CoCoSoDa} 编码器，并遵循 UA-HN~\citep{AAAIUA} 的训练配置。初始检索器、\method{}-Global 以及带重排的 \method{} 均使用相同的数据、候选代码库和评测脚本。从既有论文复制的数值会被明确标记为“已报告”，仅用于说明本文结果在领域中的位置；配对差值和置信区间只相对于在本文流程中评测的初始检查点计算。为了公平比较候选选择策略，我们为每个查询统一加入一个额外候选：随机采样的非正例（Random）、固定的预挖掘困难负例（Static），以及由冻结检索器挖掘得到的高排名非标注候选（FC）。

\paragraph{Training and model selection.}
The initial retriever is trained for 10 epochs with batch size 128, learning rate \(8\times10^{-6}\), and temperature 0.03. To construct FC supervision, we freeze this checkpoint, retrieve over the training codebase, remove the paired code and candidates with the same URL, and store the top 32 remaining candidates. Refinement retains the first eight candidates and samples one per update. We train for three epochs with batch size 128, learning rate \(5\times10^{-6}\), FC weight 0.45, and FC temperature 0.03. The final refinement objective contains no CTRD or token-level local-interaction training loss.
% 中文：初始检索器训练 10 个 epoch，批量大小为 128，学习率为 \(8\times10^{-6}\)，温度为 0.03。构造 FC 监督时，我们冻结该检查点，在训练代码库上执行检索，排除配对代码以及 URL 相同的候选，并保存排名最高的 32 个剩余候选。细化训练保留前 8 个候选，每次更新采样其中 1 个。细化阶段训练 3 个 epoch，批量大小为 128，学习率为 \(5\times10^{-6}\)，FC 权重为 0.45，FC 温度为 0.03。最终细化目标不包含 CTRD，也不包含词元级局部交互训练损失。

At inference time, \method{}-Global remains a dual encoder. The optional reranker computes a parameter-free token-level MaxSim score only for the global top-\(K\) candidates and combines the query-wise standardized global and local scores. We select \(K=20\) and fusion weight \(\alpha=0.5\) using six-language validation macro MRR and freeze both values before test evaluation. Checkpoints are also selected on validation data. All reported local results use the fixed training seed 123456 on one NVIDIA H20 GPU.
% 中文：在推理阶段，\method{}-Global 仍然是双编码器。可选重排器只对全局检索得到的前 \(K\) 个候选计算无需训练参数的词元级 MaxSim 分数，再融合按查询标准化后的全局分数与局部分数。我们依据六种语言验证集上的宏平均 MRR 选择 \(K=20\) 和融合权重 \(\alpha=0.5\)，并在测试前冻结这两个取值。模型检查点同样仅根据验证集选择。所有本地结果均使用固定训练种子 123456，并在一张 NVIDIA H20 GPU 上运行。

\paragraph{Uncertainty estimates.}
We use a stratified paired bootstrap over test queries to characterize query-sampling uncertainty in the difference between each refined system and the initial retriever. These intervals condition on the single trained checkpoint and therefore do not measure variation across training seeds.
% 中文：我们在测试查询上采用分层配对 bootstrap，刻画细化系统与初始检索器之间差值的查询采样不确定性。这些区间以单个已训练检查点为条件，因此不能衡量不同训练种子带来的波动。

Rows marked with \reported{} are copied from the cited papers and provide field context; rows marked with \localrun{} are produced by our local evaluation. Controlled deltas and confidence intervals use the matched initial checkpoint rather than the reported rows.

The recall results clarify the type of improvement. From the initial retriever to the final reranked system, R@1 increases from 70.72 to 72.64, whereas R@5 changes from 91.28 to 91.68 and R@10 from 95.10 to 95.11. The gain is therefore concentrated in ordering already retrieved candidates near the top rather than expanding broad top-10 coverage. This pattern matches the intended role of failure-candidate refinement and shallow top-\(K\) reranking.
% 中文：召回率结果进一步说明了性能提升的性质。从初始检索器到最终重排系统，R@1 从 70.72 提升到 72.64，而 R@5 仅从 91.28 变为 91.68，R@10 从 95.10 变为 95.11。因此，增益主要来自把已经检索到的候选更准确地排到前列，而不是扩大整体的前 10 名覆盖率。这与失败候选细化及浅层前 \(K\) 重排的预期作用一致。

For controlled deltas, we compare each \method{} variant with the pre-refinement checkpoint evaluated in the same pipeline. The upper block of Table~\ref{tab:main_results} provides published context, whereas the paired analyses below establish the measured improvements; differences from the reported rows alone do not establish a controlled gain.
% 中文：计算受控差值时，我们将每个 \method{} 变体与同一流程中评测的细化前检查点进行比较。表~\ref{tab:main_results} 的上半部分提供已发表结果作为背景，后续配对分析用于确定实际测得的提升；仅凭与论文报告行之间的差异不能证明受控增益。

\subsection{Does Candidate Selection Matter?}
\label{sec:candidate_controls}

Table~\ref{tab:candidate_controls} controls the number of added candidates and changes only how the candidate is selected. Neither another training stage with Random candidates nor refinement with Static hard negatives improves over no refinement. In contrast, a single retriever-mined candidate raises macro MRR by 0.35 points and R@1 by 0.83 points. This matched comparison supports the narrower claim that candidates from the trained retriever's own ranking neighborhood provide a more targeted refinement signal than the two proxy strategies tested here.
% 中文：表~\ref{tab:candidate_controls} 固定额外候选的数量，只改变候选选择方式。无论是使用 Random 候选再训练一个阶段，还是使用 Static 困难负例进行细化，其结果都没有超过未细化设置；相反，每个查询只使用一个由检索器挖掘的候选，就使宏平均 MRR 提升 0.35 个点、R@1 提升 0.83 个点。这一匹配对比支持一个更克制的结论：与本文测试的两种代理策略相比，训练完成的检索器自身排序邻域能够提供更有针对性的细化信号。

The control also exposes a trade-off: FC improves top-rank accuracy while R@10 decreases by 0.52 points in this one-candidate setting. We therefore interpret the control as evidence about top-rank discrimination, not as evidence that FC uniformly improves every retrieval depth. With the final FC budget, the global model reaches 80.57 MRR and recovers R@10 to 95.17.
% 中文：这一对照也揭示了一个权衡：在每个查询只使用一个候选的设置下，FC 提高了首位排序准确率，但 R@10 下降了 0.52 个点。因此，该实验支持的是 FC 改善前列判别能力，而不是 FC 在所有检索深度上都一致提升。采用最终 FC 候选预算后，全局模型达到 80.57 MRR，同时 R@10 恢复到 95.17。

\subsection{Where Does the Improvement Occur?}
\label{sec:rank_analysis}

We stratify all 52,561 test queries by the pre-refinement rank of the labeled code. Table~\ref{tab:rank_strata} shows that the largest gains occur when the labeled code is initially ranked at positions 2--10: \method{}-Global improves MRR by 8.89 points in this stratum, and reranking increases the gain to 11.32 points. Gains are smaller but positive at ranks 11--50 and beyond 50. These results localize the aggregate improvement to the high-ranked neighborhood targeted by the method.
% 中文：我们按照细化前标注代码的排名，对全部 52,561 个测试查询进行分层。表~\ref{tab:rank_strata} 显示，当标注代码的初始排名为第 2--10 位时，增益最大：在这一层中，\method{}-Global 将 MRR 提升 8.89 个点，加入重排后增益扩大到 11.32 个点。在第 11--50 位和 50 位以后，增益较小但仍为正。这表明总体提升主要来自本文方法所针对的高排名邻域。

The same analysis also reveals regressions that an aggregate score would hide. Relative to the pre-refinement ranking, final reranking improves the labeled-code rank for 7,121 queries and worsens it for 5,741; it repairs 2,644 non-top-1 cases to rank 1 but moves 1,624 initial top-1 cases downward. In the initial-rank-1 stratum, MRR decreases by 2.47 points. \method{} should therefore be understood as a net corrective intervention rather than a monotonic improvement for every query. Designing a gate that preserves confident initial top-1 decisions is a promising direction for future work.
% 中文：同一分析也揭示了总体指标会掩盖的回退现象。相对于细化前排序，最终重排使 7,121 个查询中的标注代码排名上升，同时使 5,741 个查询的排名下降；它把 2,644 个原本非首位的样本修复到第 1 位，但也使 1,624 个初始首位样本向后移动。在初始排名为 1 的分层中，MRR 下降了 2.47 个点。因此，\method{} 应被理解为总体收益为正的纠正干预，而不是对每个查询都单调改进。未来可以设计门控机制，以保留初始排序中置信度较高的首位判断。

\subsection{Data and Protocol Audit}
\label{sec:audit}

We audit split isolation, candidate caches, checkpoint lineage, model selection, and test invocation. Across 121 checks, 115 pass and none fail critically. Exact URL, repository, and normalized code overlap between train, validation, and test are zero; validation and test gold-code coverage is 100\%. Each FC cache contains 32 unique, in-range, training-only candidates per query and excludes the paired example and same-URL code. Recomputing model selection from validation results independently recovers \(K=20,\alpha=0.5\).
% 中文：我们审计了数据划分隔离、候选缓存、检查点来源、模型选择和测试调用。在 121 项检查中，115 项通过，没有关键失败。训练集、验证集和测试集之间的 URL、代码仓库及规范化代码的精确重叠均为零，验证集和测试集标注代码的覆盖率为 100\%。每个 FC 缓存对每个查询都包含 32 个唯一、索引有效且仅来自训练集的候选，并排除了配对样本和 URL 相同的代码。根据验证结果独立重新执行模型选择，也得到 \(K=20,\alpha=0.5\)。

The six warnings correspond to natural-language strings duplicated in the frozen upstream benchmark splits. We retain and disclose these cases rather than modifying the benchmark after observing the data. This audit establishes the integrity and provenance of the executed pipeline, but it does not establish that every non-ground-truth candidate is semantically irrelevant.
% 中文：六条警告来自冻结的上游基准划分中重复出现的自然语言文本。我们保留并披露这些样本，而不是在观察数据后修改基准。该审计能够说明实际执行流程的数据完整性和来源可追溯性，但不能证明每个非标注候选在语义上都不相关。

\subsection{Scope of the Evidence}
\label{sec:scope}

Our conclusions are deliberately limited to the audited fixed-seed pipeline. Query-level bootstrap intervals do not replace multiple independent training runs, and the present results do not establish training-seed stability. Moreover, the final no-CTRD/no-local-training configuration has not yet been fully evaluated across multiple backbone families under matched protocols. We therefore claim improvement under the present experimental configuration, not universal backbone independence.
% 中文：本文结论被有意限定在已经审计的固定种子流程内。查询级 bootstrap 区间不能替代多个独立训练实验，当前结果也不能证明随机种子稳定性。此外，最终的无 CTRD、无局部交互训练配置尚未在多个骨干模型上按照一致协议进行完整评测。因此，我们主张的是当前实验配置下的提升，而不是已经证明了对任意骨干模型都有效。

Finally, CodeSearchNet provides one labeled code snippet per query, so a high-ranked non-ground-truth candidate may be a valid alternative implementation. Our method uses these candidates as challenging contrastive supervision without asserting that they are genuine semantic errors. A double-annotated candidate study would be needed to quantify alternative positives and fine-grained mismatch categories.
% 中文：最后，CodeSearchNet 每个查询只提供一个标注代码，因此高排名的非标注候选可能是有效的替代实现。本文仅把这些候选当作具有挑战性的对比监督，并不声称它们一定是真实的语义错误。若要量化替代正例以及细粒度语义不匹配类别，还需要开展双人标注的候选分析。

\section*{Limitations}

Our evidence is limited to CodeSearchNet, one audited training seed, and one encoder and training configuration. Query-level bootstrap intervals quantify evaluation-set uncertainty but do not establish stability across independent training runs. CodeSearchNet also provides only one labeled code snippet per query, so some high-ranked non-ground-truth candidates may be valid alternative implementations. Finally, the parameter-free reranker adds latency over global retrieval, and the current transfer evidence is insufficient to claim backbone independence.
% 中文：当前证据仅覆盖 CodeSearchNet、一个经过审计的训练随机种子，以及一种编码器和训练配置。查询级 bootstrap 区间能够刻画评测集不确定性，但不能证明不同独立训练之间的稳定性。CodeSearchNet 每个查询只提供一个标注代码，因此部分高排名非标注候选可能是有效的替代实现。此外，无参数重排器会在全局检索之上增加延迟，现有迁移证据也不足以支持骨干模型无关性的结论。
