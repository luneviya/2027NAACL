\begin{abstract}
Contrastive code search is commonly trained with in-batch, random, or statically mined negatives, although inference errors are determined by the few high-scoring candidates returned by the trained retriever. We present \method{}, a failure-calibrated refinement framework that freezes an initial retriever, harvests its high-ranked unpaired candidates, and turns them into targeted contrastive supervision. A separately weighted failure-candidate loss refines global query--code representations according to their positive--negative score margins; an optional inference stage then applies token-level MaxSim and Global--Local Score Fusion only within the retrieved top-\(K\). Under a matched local protocol on the six-language CodeSearchNet benchmark, \method{}-Global raises macro-averaged MRR from 79.77 to 80.57, and \method{}-Rerank reaches 81.06. The complete system improves MRR by 1.29 points over the initial retriever, with a paired-bootstrap 95\% confidence interval of [1.11, 1.47] over test queries. Budget-matched candidate controls favor Failure Candidate Harvesting over random and static alternatives, and rank-conditioned analysis locates the largest gains among queries whose paired code initially ranks 2--10. The full pipeline can be instantiated with CoCoSoDa, UniXcoder, and GraphCodeBERT, with MaxSim improving MRR for each refined checkpoint.
% 中文：对比式代码搜索通常使用批内、随机或静态挖掘的负样本进行训练，但推理错误实际由训练完成的检索器返回的少量高分候选决定。本文提出 \method{}，一种失败校准的细化框架：它冻结初始检索器，挖掘其高排名未配对候选，并将这些候选转化为有针对性的对比监督。单独加权的失败候选损失根据正负样本分数间隔细化全局查询—代码表示；可选的推理阶段随后仅在检索得到的前 \(K\) 个候选内应用词元级 MaxSim 和全局—局部分数融合。在六语言 CodeSearchNet 基准的协议一致本地评测中，\method{}-Global 将宏平均 MRR 从 79.77 提升至 80.57，\method{}-Rerank 进一步达到 81.06。完整系统相对于初始检索器提升 1.29 个 MRR 点，测试查询上的配对 bootstrap 95\% 置信区间为 [1.11, 1.47]。预算匹配的候选对照表明，失败候选挖掘优于随机与静态替代方案；按排名分层的分析则显示，最大收益来自配对代码初始位于第 2--10 名的查询。完整流程可分别使用 CoCoSoDa、UniXcoder 和 GraphCodeBERT 实例化，且 MaxSim 均能提高相应细化检查点的 MRR。
\end{abstract}

\section{Introduction}
\label{sec:introduction}

Code search maps natural-language intent to executable implementations. Modern systems encode queries and code independently, then rank a corpus by similarity in a shared representation space~\citep{CodeBERT,GraphCodeBERT,UniXcoder}. This dual-encoder design enables efficient full-corpus retrieval, while contrastive pre-training and fine-tuning align paired queries and code~\citep{CodeRetriever,CoCoSoDa}. Its effectiveness, however, depends critically on which unpaired examples define the contrastive competitors.
% 中文：代码搜索将自然语言意图映射到可执行实现。现代系统分别编码查询与代码，再根据共享表示空间中的相似度对语料库排序~\citep{CodeBERT,GraphCodeBERT,UniXcoder}。这种双编码器设计支持高效的全库检索，对比式预训练与微调则对齐配对查询和代码~\citep{CodeRetriever,CoCoSoDa}。然而，其效果关键取决于哪些未配对样本构成对比竞争项。

Standard objectives draw negatives from the current minibatch, random sampling, or static pools independent of the final retriever's rankings. These negatives need not match the candidates that determine inference errors. After training, only corpus items assigned an equal or larger score can outrank the paired code, and these comparisons concentrate among a few high-ranked alternatives. In \emph{Retrieved-but-Mis-ranked Cases}, the paired code is already near the top but remains below one or more competitors. Figure~\ref{fig:problem_setting} illustrates why improving such cases requires supervision from the initial retriever's full-corpus rankings.
% 中文：标准目标从当前小批量、随机采样或独立于最终检索器排序的静态候选池中获取负样本，但这些负样本未必对应推理时决定错误的候选。训练完成后，只有得分不低于配对代码的语料项才能使其排名后移，而这类比较集中于少量高排名替代候选。在“已检索但排序错误案例”（Retrieved-but-Mis-ranked Cases）中，配对代码已位于顶部附近，却仍排在一个或多个竞争候选之后。图~\ref{fig:problem_setting} 说明了为何改善此类案例需要来自初始检索器全库排序的监督。

We therefore propose \method{}, a three-stage failure-calibrated contrastive refinement framework. \emph{Failure Candidate Harvesting} freezes the initial retriever and collects its highest-ranked unpaired code after excluding the paired example and candidates sharing its URL. \emph{Failure-Calibrated Contrastive Refinement} adds a separately weighted contrastive loss over these candidates while preserving the base objective. Optional \emph{Dual-Granularity Reranking} applies token-level MaxSim and \emph{Global--Local Score Fusion} within the global top-\(K\). Harvesting and refinement form the training procedure; reranking adds no trainable parameters but incurs inference cost.
% 中文：为此，我们提出 \method{}，一种三阶段失败校准对比细化框架。\emph{失败候选挖掘（Failure Candidate Harvesting）}冻结初始检索器，在排除配对样本及共享其 URL 的候选后收集排名最高的未配对代码。\emph{失败校准对比细化（Failure-Calibrated Contrastive Refinement）}保留基础目标，并在这些候选上增加单独加权的对比损失。可选的\emph{双粒度重排（Dual-Granularity Reranking）}在全局前 \(K\) 个候选内应用词元级 MaxSim 和\emph{全局—局部分数融合（Global--Local Score Fusion）}。候选挖掘与细化构成训练流程；重排不增加可训练参数，但会带来推理成本。

The positive--negative score margin explains the refinement signal: a small or negative margin produces a larger loss contribution, so candidates closest to displacing the paired code exert the strongest pressure. The update acts on rank-determining score comparisons, while MRR remains an evaluation metric rather than a training objective. Consistently, the largest gains occur when the paired code initially ranks 2--10.
% 中文：正负样本分数间隔说明了细化信号：较小或为负的间隔产生更大的损失贡献，因此最接近挤压配对代码排名的候选会施加最强压力。更新作用于决定排名的分数比较，而 MRR 仍是评测指标而非训练目标。与此一致，当配对代码初始位于第 2--10 名时，收益最大。

Under a matched local protocol on all six CodeSearchNet languages~\citep{CodeSearchNet}, \method{}-Global raises macro MRR from 79.77 to 80.57 and R@1 from 70.72 to 71.90; optional reranking reaches 81.06 MRR and 72.64 R@1. Budget-matched controls favor retriever-mined Failure Candidates over random and static alternatives. Paired-bootstrap intervals quantify test-query sampling uncertainty for the fixed checkpoints, and three encoder instantiations examine pipeline compatibility.
% 中文：在全部六种 CodeSearchNet 语言~\citep{CodeSearchNet}上的协议一致本地评测中，\method{}-Global 将宏平均 MRR 从 79.77 提升至 80.57，并将 R@1 从 70.72 提升至 71.90；可选重排达到 81.06 MRR 和 72.64 R@1。预算匹配的对照表明，检索器挖掘的失败候选优于随机和静态替代方案。配对 bootstrap 区间衡量固定检查点上的测试查询采样不确定性，三种编码器实例则考察流程兼容性。

Global refinement changes the representation space used for every corpus comparison, whereas optional reranking revisits only retrieved candidates. Evaluating them separately distinguishes training-side improvement from token-level inference.
% 中文：全局细化改变所有语料库比较所使用的表示空间，而可选重排只重新考察检索得到的候选。分别评测二者可以区分训练侧改进与词元级推理效果。

Our contributions are threefold:
% 中文：本文的贡献有三点：
\begin{itemize}
  \item We introduce \method{}, which converts high-ranked unpaired candidates from a frozen initial retriever into model-specific supervision while retaining efficient full-corpus dual-encoder retrieval.
  % 中文：我们提出 \method{}，将冻结初始检索器返回的高排名未配对候选转化为模型特定监督，同时保留高效的全库双编码器检索。
  \item We connect refinement to positive--negative score margins and isolate its source with budget-matched candidate controls and rank-conditioned analysis, locating the principal gains in near-top misrankings.
  % 中文：我们将细化与正负样本分数间隔联系起来，并通过预算匹配的候选对照和按排名分层的分析隔离其来源，将主要收益定位于接近顶部的错误排序。
  \item In a controlled six-language evaluation, global refinement improves the matched initial retriever by 0.80 MRR points, and optional Dual-Granularity Reranking raises the complete improvement to 1.29 points, with explicit uncertainty and efficiency reporting.
  % 中文：在六语言受控评测中，全局细化相对于协议一致的初始检索器提升 0.80 个 MRR 点，可选的双粒度重排将完整系统的提升扩大至 1.29 个点，并显式报告不确定性与效率。
\end{itemize}

\section{Related Work}
\label{sec:related_work}

\subsection{Neural Code Search}

Neural code search learns a shared space in which natural-language queries retrieve source code. CodeBERT transfers bimodal code--text representations, GraphCodeBERT incorporates data-flow structure, and UniXcoder unifies cross-modal pre-training~\citep{CodeBERT,GraphCodeBERT,UniXcoder}. CodeRetriever and CoCoSoDa further strengthen contrastive representation learning~\citep{CodeRetriever,CoCoSoDa}. Together, these advances establish dual encoders that support offline code indexing and efficient full-corpus retrieval.
% 中文：神经代码搜索学习一个共享空间，使自然语言查询能够检索源代码。CodeBERT 迁移双模态代码—文本表示，GraphCodeBERT 融入数据流结构，UniXcoder 则统一跨模态预训练~\citep{CodeBERT,GraphCodeBERT,UniXcoder}。CodeRetriever 与 CoCoSoDa 进一步强化对比式表示学习~\citep{CodeRetriever,CoCoSoDa}。这些进展共同奠定了双编码器，使代码能够离线建立索引，并支持高效的全库检索。

Recent systems also strengthen supervision through task-specific negatives and auxiliary relevance objectives~\citep{AAAIUA,HedgeCode}. These approaches improve the encoder or its initial training signal, but construct that signal before the final full-corpus ranking is available. \method{} instead treats a trained initial retriever as a source of supervision: it freezes the model, observes which unpaired snippets receive high scores in corpus retrieval, and refines the same dual-encoder space with those candidates. This staging makes the refinement complementary to pre-training, encoder structure, and the initial loss.
% 中文：近期系统还通过任务特定负样本和辅助相关性目标强化监督~\citep{AAAIUA,HedgeCode}。这些方法改进编码器或其初始训练信号，但相应信号是在最终全库排序可用之前构造的。\method{} 则将训练完成的初始检索器视为监督来源：冻结模型，观察哪些未配对代码在全库检索中获得高分，再利用这些候选细化同一个双编码器空间。这样的阶段划分使细化能够与预训练、编码器结构及初始损失的改进互为补充。

Preserving independent code representations matters for large-corpus search: a refined index can replace the initial one without changing the retrieval interface. \method{} therefore changes dual-encoder supervision with retrieved rankings while confining richer query--code interaction to optional top-\(K\) reranking.
% 中文：保留独立的代码表示对于大规模语料库检索十分重要：细化后的索引可以替换初始索引，而无需改变检索接口。因此，\method{} 利用检索排序改变双编码器监督，同时将更丰富的查询—代码交互限制在可选的前 \(K\) 名重排阶段。

\subsection{Hard Negatives and Late Interaction}

Hard-negative mining replaces easy random negatives with candidates that better challenge the representation space. ANCE retrieves negatives from an evolving index, while RocketQA combines large negative pools with denoising~\citep{ANCE,RocketQA}; code-search work also uses uncertainty-aware sampling~\citep{AAAIUA}. These methods primarily make the training distribution more informative. Mining policies also differ in whether candidate identities evolve with the learner: online retrieval can refresh them as training proceeds, whereas model-independent static pools do not adapt to the final retriever's rankings. Failure Candidate Harvesting uses a third arrangement. Its pool is model-specific because the trained initial retriever produces it, yet fixed throughout refinement. The method records query-specific full-corpus rankings and uses the highest-ranked unpaired candidates in a separate refinement stage. Candidate difficulty is therefore defined relative to the behavior of the trained initial retriever, rather than by a model-independent pool alone. Because benchmark pairing does not establish semantic invalidity, ``failure candidate'' denotes the candidate's operational role in refinement, not a semantic label.
% 中文：困难负样本挖掘以更能挑战表示空间的候选替代简单随机负样本。ANCE 从持续更新的索引中检索负样本，RocketQA 结合大规模负样本池与去噪~\citep{ANCE,RocketQA}；代码搜索研究也采用不确定性感知采样~\citep{AAAIUA}。这些方法主要用于提高训练分布的信息量。挖掘策略还取决于候选身份是否随学习器演化：在线检索可以在训练过程中刷新候选，而与模型无关的静态候选池不会适应最终检索器的排序。失败候选挖掘采用第三种安排：候选池由训练完成的初始检索器生成，因此具有模型特异性；但在整个细化阶段保持固定。该方法记录针对各查询的全库排序，并在独立细化阶段使用排名最高的未配对候选。因此，候选难度由训练完成的初始检索器的实际行为界定，而不只由与模型无关的候选池决定。由于基准配对关系并不能判定语义无效，“失败候选”描述的是候选在细化中的操作性角色，而不是语义标签。

Late interaction complements global retrieval by retaining token representations and aggregating token-wise similarities; ColBERT's MaxSim is representative~\citep{ColBERT}. Applying these interactions throughout a corpus would sacrifice the main efficiency advantage of dual encoders. \method{} instead preserves global representations for training and full-corpus search, then optionally applies MaxSim only within the retrieved top-\(K\). Global--Local Score Fusion combines the standardized scores without additional trainable parameters, while retaining a measurable inference cost.
% 中文：后期交互通过保留词元表示并聚合逐词元相似度来补充全局检索；ColBERT 的 MaxSim 是代表性形式~\citep{ColBERT}。若在整个语料库范围内应用此类交互，会损失双编码器的主要效率优势。\method{} 在训练与全库搜索中保留全局表示，随后仅在检索得到的前 \(K\) 个候选内可选地应用 MaxSim。全局—局部分数融合在不增加可训练参数的情况下组合标准化分数，同时保留可测量的推理开销。

\section{Method}
\label{sec:method}

Figure~\ref{fig:framework} summarizes the three stages of \method{}. Failure Candidate Harvesting collects high-ranked unpaired alternatives from a frozen initial retriever, and Failure-Calibrated Contrastive Refinement uses these model-specific candidates to update the global retrieval space. The refined dual encoder retrieves from the complete corpus; optional Dual-Granularity Reranking then combines sequence-level and token-level evidence within the retrieved top-\(K\).
% 中文：图~\ref{fig:framework} 概述了 \method{} 的三个阶段。失败候选挖掘从冻结的初始检索器中收集高排名未配对替代项，失败校准对比细化利用这些模型特定候选更新全局检索空间。细化后的双编码器从完整语料库中检索；可选的双粒度重排再在检索得到的前 \(K\) 个候选内融合序列级与词元级证据。

\subsection{Problem Formulation}
\label{sec:problem_formulation}

Let \(\mathcal{D}=\{(q_i,c_i^+)\}_{i=1}^{N}\) denote a code-search training set, where \(q_i\) is a natural-language query and \(c_i^+\) is its paired code snippet. A dual encoder maps queries and code into a shared space through \(f_\theta\) and \(g_\theta\). After \(\ell_2\) normalization, their global retrieval score is
% 中文：设 \(\mathcal{D}=\{(q_i,c_i^+)\}_{i=1}^{N}\) 表示代码搜索训练集，其中 \(q_i\) 是自然语言查询，\(c_i^+\) 是与之配对的代码片段。双编码器分别通过 \(f_\theta\) 和 \(g_\theta\) 将查询与代码映射到共享空间。经过 \(\ell_2\) 归一化后，其全局检索分数定义为
\begin{equation}
  s_\theta(q,c)=f_\theta(q)^{\top}g_\theta(c).
  \label{eq:global_score}
\end{equation}

For a competing candidate \(c^-\), define the score margin as
% 中文：对于竞争候选 \(c^-\)，分数间隔定义为
\begin{equation}
  \mu_\theta(q_i,c^-)
  =s_\theta(q_i,c_i^+)-s_\theta(q_i,c^-).
  \label{eq:score_margin}
\end{equation}
The rank of the paired code can then be written as
% 中文：配对代码的排名可写为
\begin{equation}
  \operatorname{rank}_\theta(c_i^+\mid q_i)
  =1+\sum_{c\in\mathcal{C}\setminus\{c_i^+\}}
  \mathbb{I}\!\left[\mu_\theta(q_i,c)\leq 0\right],
  \label{eq:rank_margin}
\end{equation}
where \(\mathcal{C}\) is the retrieval corpus. Equations~\ref{eq:score_margin} and~\ref{eq:rank_margin} make the relevant score comparisons explicit: a negative margin identifies a candidate that already outranks the paired code, while a small positive margin identifies a nearby competitor whose order can be reversed by a modest score change. Both are more informative for refinement than candidates already separated by a large margin. Conventional in-batch or statically mined negatives are selected before the final retriever is observed and need not coincide with these model-specific competitors. \method{} therefore conditions refinement on the ranking behavior of a trained initial retriever, while retaining MRR strictly as an evaluation metric.
% 中文：其中 \(\mathcal{C}\) 表示检索语料库。式~\ref{eq:score_margin} 与式~\ref{eq:rank_margin} 明确了与排序相关的分数比较：负间隔表示某个候选已经排在配对代码之前，较小的正间隔则表示一个只需较小分数变化就可能发生次序逆转的邻近竞争候选。与已经被大间隔分开的候选相比，这两类候选能为细化提供更有针对性的信息。常规批内负例或静态挖掘负例是在最终检索器行为被观察之前选取的，因此未必与这些模型特定的竞争候选一致。基于此，\method{} 根据训练完成的初始检索器所产生的排序行为开展细化，同时严格将 MRR 保留为评测指标。

Competitors are query dependent: a code snippet may rank low for one query yet highly for another. Refinement therefore associates each query with candidates from its own corpus ranking, preserving the link between observed scores and subsequent contrastive comparisons.
% 中文：竞争候选依赖于具体查询：同一代码片段在一个查询下可能排名较低，却可能在另一个查询下排名很高。因此，细化为每个查询关联其自身语料库排序中的候选，从而保留观测分数与后续对比比较之间的对应关系。

\subsection{Failure Candidate Harvesting}
\label{sec:failure_harvesting}

We first train an initial retriever with the underlying contrastive code-search objective and freeze its parameters \(\theta_0\). For every training query, the frozen model retrieves from the training code corpus. Let \(\mathcal{E}_i\) contain the paired code and all candidates sharing its URL. We remove \(\mathcal{E}_i\) and retain the \(M\) highest-scoring candidates:
% 中文：我们首先使用基础对比式代码搜索目标训练初始检索器，并冻结其参数 \(\theta_0\)。对于每个训练查询，冻结模型在训练代码语料库中执行检索。令 \(\mathcal{E}_i\) 包含配对代码以及与其共享 URL 的所有候选；移除 \(\mathcal{E}_i\) 后，保留得分最高的 \(M\) 个候选：
\begin{equation}
  \begin{aligned}
    \mathcal{H}_i
    &=\operatorname{Top}_{M}^{s_{\theta_0}(q_i,\cdot)}
      (\mathcal{C}_{\mathrm{train}}\setminus\mathcal{E}_i), \\
    \mathcal{F}_i
    &=\operatorname{Top}_{m}^{s_{\theta_0}(q_i,\cdot)}(\mathcal{H}_i).
  \end{aligned}
  \label{eq:fc_pool}
\end{equation}

We call members of \(\mathcal{F}_i\) \emph{failure candidates}: they are the initial retriever's strongest unpaired alternatives for \(q_i\) and directly instantiate the score comparisons that determine rank in Equation~\ref{eq:rank_margin}. This is an operational designation based on benchmark pairing and retrieval rank; it does not assume that every unpaired candidate is semantically invalid. The two truncation levels serve different roles. \(M\) bounds the persistent pool produced by corpus retrieval, whereas \(m\) restricts the high-ranked prefix exposed to refinement; sampling \(r\) entries from that prefix controls the additional per-update comparison budget. The pool is generated once from the frozen initial retriever, preserving model specificity without repeating corpus-wide retrieval at every update. Freezing \(\theta_0\) also separates candidate discovery from parameter updates: candidate identities and their initial order remain fixed while \(\theta\) changes during refinement.
% 中文：我们将 \(\mathcal{F}_i\) 中的元素称为“失败候选”：它们是初始检索器针对 \(q_i\) 返回的最强未配对替代项，并直接构成式~\ref{eq:rank_margin} 中决定排名的分数比较。该名称是依据基准配对关系和检索排名给出的操作性定义，并不假设每个未配对候选在语义上都无效。两个截断层次具有不同作用：\(M\) 限制全库检索后持久化候选池的规模，\(m\) 则限制细化阶段可见的高排名前缀；从该前缀采样 \(r\) 个条目用于控制每次更新新增的比较预算。候选池仅由冻结的初始检索器生成一次，从而保留模型特异性，同时避免在每次参数更新时重复执行全语料库检索。冻结 \(\theta_0\) 还将候选发现与参数更新分开：在细化过程中，候选身份及其初始次序保持固定，而 \(\theta\) 持续更新。

\subsection{Failure-Calibrated Contrastive Refinement}
\label{sec:failure_refinement}

Starting from \(\theta_0\), we retain the initial retriever's contrastive objective \(\mathcal{L}_{\mathrm{base}}\) and introduce a listwise objective over the harvested candidates. For a minibatch \(\mathcal{B}\), let \(\mathcal{S}_i\subseteq\mathcal{F}_i\) contain the \(r\) candidates sampled for query \(q_i\). The failure-candidate loss is
% 中文：以 \(\theta_0\) 为起点，我们保留初始检索器的对比目标 \(\mathcal{L}_{\mathrm{base}}\)，并对挖掘得到的候选引入 listwise 目标。对于小批量 \(\mathcal{B}\)，设 \(\mathcal{S}_i\subseteq\mathcal{F}_i\) 包含为查询 \(q_i\) 采样的 \(r\) 个候选。失败候选损失定义为
\begin{equation}
  \mathcal{L}_{\mathrm{FC}}^{i}
  =-\log
  \frac{\exp(s_\theta(q_i,c_i^+)/\tau_f)}
  {\begin{aligned}
     &\exp(s_\theta(q_i,c_i^+)/\tau_f) \\
     &\quad+\sum_{c\in\mathcal{S}_i}
       \exp(s_\theta(q_i,c)/\tau_f)
   \end{aligned}},
  \label{eq:fc_loss}
\end{equation}
and the complete refinement objective is
% 中文：完整的细化目标为
\begin{equation}
  \mathcal{L}_{\mathrm{ref}}
  =\mathcal{L}_{\mathrm{base}}
  +\frac{\lambda_f}{|\mathcal{B}|}
   \sum_{i\in\mathcal{B}}\mathcal{L}_{\mathrm{FC}}^{i}.
  \label{eq:refinement_loss}
\end{equation}

Equation~\ref{eq:refinement_loss} keeps \(\mathcal{L}_{\mathrm{FC}}\) separate from \(\mathcal{L}_{\mathrm{base}}\): \(\lambda_f\) weights the separately computed failure-candidate loss rather than modifying logits inside the base softmax denominator. The original contrastive comparisons are therefore preserved, while the strength of the targeted failure-candidate signal can be controlled independently.
% 中文：式~\ref{eq:refinement_loss} 将 \(\mathcal{L}_{\mathrm{FC}}\) 与 \(\mathcal{L}_{\mathrm{base}}\) 分开计算：\(\lambda_f\) 对单独计算的失败候选损失加权，而不是修改基础 softmax 分母中的 logit。因此，原有对比关系得以保留，同时可以独立控制针对失败候选的监督信号强度。

\paragraph{Score-margin interpretation.}
The added term admits a direct score-margin form,
% 中文：新增损失项可直接写成分数间隔形式：
\begin{equation}
  \mathcal{L}_{\mathrm{FC}}^{i}
  =\log\!\left(1+\sum_{c\in\mathcal{S}_i}
  \exp[-\mu_\theta(q_i,c)/\tau_f]\right).
  \label{eq:margin_loss}
\end{equation}
Candidates with smaller or negative margins consequently exert greater optimization pressure: their exponential terms occupy more mass in Equation~\ref{eq:margin_loss}, producing a larger-magnitude gradient with respect to the corresponding margin. The coefficient \(\lambda_f\) calibrates this targeted signal against the initial retriever's training objective. Training uses only global representations; token-level local interaction and CTRD are not part of the refinement objective.
% 中文：因此，分数间隔更小或为负的候选会产生更强的优化压力：它们的指数项在式~\ref{eq:margin_loss} 中占据更大权重，从而对相应分数间隔产生幅度更大的梯度。系数 \(\lambda_f\) 用于校准这一针对性信号相对于初始检索器训练目标的权重。训练仅使用全局表示；词元级局部交互和 CTRD 不属于细化目标。

\subsection{Dual-Granularity Reranking}
\label{sec:reranking_method}

Global retrieval remains responsible for searching the complete corpus. To resolve fine-grained distinctions only where they can affect the returned ranking, we optionally rescore its top-\(K\) candidates with MaxSim~\citep{ColBERT}. Let \(\{\mathbf{h}^{q}_{a}\}_{a=1}^{T_q}\) and \(\{\mathbf{h}^{c}_{b}\}_{b=1}^{T_c}\) be the token representations of a query and candidate code. Their local-interaction score is
% 中文：全局检索仍负责在完整语料库中进行搜索。为了仅在可能影响最终排名的位置解析细粒度差异，我们可选地使用 MaxSim~\citep{ColBERT} 对其前 \(K\) 个候选重新计分。设 \(\{\mathbf{h}^{q}_{a}\}_{a=1}^{T_q}\) 和 \(\{\mathbf{h}^{c}_{b}\}_{b=1}^{T_c}\) 分别为查询与候选代码的词元表示，其局部交互分数为
\begin{equation}
  s_m(q,c)=\frac{1}{T_q}\sum_{a=1}^{T_q}
  \max_{1\leq b\leq T_c}
  \cos(\mathbf{h}^{q}_{a},\mathbf{h}^{c}_{b}).
  \label{eq:maxsim}
\end{equation}

Because global and token-level scores have different query-dependent scales, each is standardized over the same top-\(K\) set. The final score is
% 中文：由于全局分数与词元级分数具有不同且依赖查询的数值尺度，我们在同一前 \(K\) 候选集合内分别对二者进行标准化。最终分数定义为
\begin{equation}
  s_r(q,c)=\alpha\widetilde{s}_\theta(q,c)
  +(1-\alpha)\widetilde{s}_m(q,c).
  \label{eq:fusion}
\end{equation}
Only candidates inside the top-\(K\) set are reordered; all remaining corpus items preserve their global-retrieval order. This stage adds no trainable parameters and is selected independently from the training objective. It does, however, incur token-level inference cost, which we measure explicitly in Section~\ref{sec:efficiency}.
% 中文：只有前 \(K\) 集合内的候选会被重新排序，其余语料库条目保持全局检索产生的顺序。该阶段不增加可训练参数，并与训练目标独立选择；但它会带来词元级推理开销，我们在第~\ref{sec:efficiency} 节中对此进行显式测量。

\paragraph{Implementation and controlled comparisons.}

\subsection{Component and Candidate-Selection Analysis}
\label{sec:component_analysis}

\paragraph{Component contributions.}
Table~\ref{tab:ablation} crosses failure-candidate refinement with MaxSim reranking under a shared inference configuration (\(K=20\), \(\alpha=0.5\)). Applied directly to the initial retriever, MaxSim raises MRR from 79.77 to 80.36. \section{Conclusion}
\label{sec:conclusion}

We presented \method{}, which converts high-ranked unpaired candidates exposed by a frozen initial retriever into margin-sensitive contrastive refinement. The refined dual encoder retains full-corpus global retrieval, with optional Dual-Granularity Reranking confined to its top-\(K\) and exposing an explicit effectiveness--latency trade-off. Under a matched six-language CodeSearchNet protocol, refinement raises macro MRR from 79.77 to 80.57 and the complete system reaches 81.06. Candidate controls favor retriever-mined supervision over equal-budget random and static alternatives, while rank-conditioned analysis locates the principal gains at initial ranks 2--10. These results support failure-calibrated refinement for the evaluated benchmark and fixed checkpoints.
% 中文：本文提出 \method{}，将冻结初始检索器暴露的高排名未配对候选转化为对分数间隔敏感的对比细化。细化后的双编码器保留全库全局检索，可选的双粒度重排仅作用于其前 \(K\) 个候选，并呈现明确的效果—延迟权衡。在六语言 CodeSearchNet 的协议一致评测中，细化将宏平均 MRR 从 79.77 提升至 80.57，完整系统达到 81.06。候选对照显示，检索器挖掘监督优于等预算的随机与静态替代方案；按排名分层的分析则将主要收益定位于初始第 2--10 名。上述结果支持失败校准细化在当前基准与固定检查点上的有效性。

\newpage
\section*{Limitations}

Our evidence is limited to CodeSearchNet and one audited training seed. The paired bootstrap intervals quantify uncertainty induced by the finite test sample, but they do not capture variation across independent retraining runs. CodeSearchNet also provides only one paired code snippet per query, so some high-ranked unpaired candidates may be valid alternative implementations; the operational term \emph{failure candidate} should not be interpreted as a semantic judgment. The encoder-instantiation experiments demonstrate end-to-end compatibility, but the absence of locally evaluated initial checkpoints under the same encoder-specific settings prevents protocol-matched estimates of their refinement gains. Finally, MaxSim introduces no trainable parameters but increases inference latency through top-\(K\) token interactions.
% 中文：当前证据仅覆盖 CodeSearchNet 和一个经过审计的训练随机种子。配对 bootstrap 区间衡量有限测试样本引起的不确定性，但不能反映独立重新训练之间的变化。CodeSearchNet 每个查询也只提供一个配对代码片段，因此部分高排名未配对候选可能是有效替代实现；“失败候选”这一操作性术语不应被理解为语义判断。编码器实例化实验说明完整流程具有端到端兼容性，但由于缺少相同编码器特定设置下的本地初始检查点评测，尚不能估计协议完全匹配的细化增益。最后，MaxSim 虽不增加可训练参数，却会因前 \(K\) 候选的词元交互而增加推理延迟。

\section{Retrieval Behavior by Initial Paired-Code Rank}
\label{app:rank_analysis}
