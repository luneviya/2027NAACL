\begin{abstract}
Dual-encoder code search is commonly trained with minibatch, random, or statically mined negatives, whereas inference errors are determined by the few high-scoring competitors returned for each query by the trained retriever. These rank-determining comparisons need not be represented by the negatives used during initial training, especially in Retrieved-but-Mis-ranked Cases where the paired code is already near the top. We introduce \method{} (Retriever Feedback for Code Search), a second-stage framework that freezes the initial retriever and converts its full-corpus rankings into fixed, query-specific Failure Candidate Pools. Failure-Calibrated Contrastive Refinement applies a separate contrastive loss to candidates in these pools, assigning stronger optimization pressure to smaller or negative positive--negative score margins while retaining efficient global retrieval. This training procedure yields \method{}-Global; \method{}-Rerank further applies Dual-Granularity Reranking within the retrieved top-\(K\) by fusing global and token-level MaxSim scores. Under a matched six-language CodeSearchNet protocol, \method{}-Global raises macro MRR from 79.8 to 80.6, and \method{}-Rerank reaches 81.1. Budget-matched controls favor retriever-harvested candidates over random and static alternatives, while rank-conditioned analysis locates the largest gains at initial ranks 2--10.
% 中文：双编码器代码搜索通常使用小批量负例、随机负例或静态挖掘负例进行训练，而推理错误取决于训练完成的检索器为每个查询返回的少量高分竞争候选。初始训练所用负例未必覆盖这些决定排名的比较，尤其是在配对代码已接近顶部的“已检索但排序错误案例”（Retrieved-but-Mis-ranked Cases）中。本文提出 \method{}（Retriever Feedback for Code Search），一种第二阶段框架：冻结初始检索器，并将其全库排序转化为固定的、逐查询的失败候选池（Failure Candidate Pools）。失败校准对比细化（Failure-Calibrated Contrastive Refinement）对候选池中的条目计算独立的对比损失，在保留高效全局检索的同时，对正负样本分数间隔较小或为负的候选施加更强优化压力。该训练流程得到 \method{}-Global；\method{}-Rerank 进一步在检索得到的前 \(K\) 个候选内执行双粒度重排（Dual-Granularity Reranking），融合全局分数与词元级 MaxSim 分数。在六语言 CodeSearchNet 的协议一致评测中，\method{}-Global 将宏平均 MRR 从 79.8 提升至 80.6，\method{}-Rerank 达到 81.1。预算匹配的对照表明，检索器挖掘候选优于随机和静态替代方案；按排名分层的分析将最大收益定位于初始第 2--10 名。
\end{abstract}

\section{Introduction}
\label{sec:introduction}

Code search maps natural-language intent to executable implementations and supports program comprehension and reuse~\citep{CodeSearchSurvey}. Modern systems encode queries and code independently, then rank a corpus by similarity in a shared representation space~\citep{CodeBERT,GraphCodeBERT,UniXcoder}. This dual-encoder design enables efficient full-corpus retrieval, while contrastive pre-training and fine-tuning align paired queries and code~\citep{CodeRetriever,CoCoSoDa}.
% 中文：代码搜索将自然语言意图映射到可执行实现，并为程序理解与复用提供支持~\citep{CodeSearchSurvey}。现代系统分别编码查询与代码，再根据共享表示空间中的相似度对语料库排序~\citep{CodeBERT,GraphCodeBERT,UniXcoder}。这种双编码器设计支持高效的全库检索，对比式预训练与微调则对齐配对查询和代码~\citep{CodeRetriever,CoCoSoDa}。

The effectiveness of contrastive training depends on the examples that define its competing set. Standard objectives draw negatives from the current minibatch, random sampling, or static pools formed without the trained retriever's full-corpus rankings. At inference time, however, a paired code snippet is displaced only by corpus items assigned an equal or higher score. Figure~\ref{fig:problem_setting} illustrates a Retrieved-but-Mis-ranked Case: the paired code is already near the top, yet one or more high-scoring alternatives remain above it. This supervision mismatch motivates using the frozen initial retriever's own rankings as feedback for a separate refinement stage.
% 中文：对比训练的效果取决于哪些样本构成其竞争集合。标准目标从当前小批量、随机采样或静态候选池中获取负例，而这些候选池并未利用训练完成的检索器所产生的全库排序。推理时，只有得分不低于配对代码的语料项才会使其排名后移。图~\ref{fig:problem_setting} 展示了一个“已检索但排序错误案例”（Retrieved-but-Mis-ranked Case）：配对代码已经接近顶部，却仍有一个或多个高分替代候选排在它之前。这一监督错位促使我们将冻结初始检索器自身的排序作为独立细化阶段的反馈信号。

We therefore propose \method{} (Retriever Feedback for Code Search), a three-stage framework driven by the fixed rankings of a trained retriever. \textbf{Failure Candidate Harvesting} excludes the paired example and same-URL candidates, then converts the remaining high-ranked results into a query-specific \textbf{Failure Candidate Pool}. \textbf{Failure-Calibrated Contrastive Refinement} applies a separately weighted contrastive loss to that pool while preserving the base objective. Its positive--negative score-margin form gives candidates with smaller or negative margins greater optimization pressure. These two stages produce \method{}-Global, which retains full-corpus dual-encoder retrieval. \method{}-Rerank enables \textbf{Dual-Granularity Reranking}: token-level MaxSim and \textbf{Global--Local Score Fusion} reorder only the retrieved top-\(K\), adding no trainable parameters but incurring inference cost.
% 中文：为此，我们提出 \method{}（Retriever Feedback for Code Search），一种由训练完成的检索器固定排序驱动的三阶段框架。\textbf{失败候选挖掘（Failure Candidate Harvesting）}排除配对样本和同 URL 候选，再将其余高排名结果转化为逐查询的\textbf{失败候选池（Failure Candidate Pool）}。\textbf{失败校准对比细化（Failure-Calibrated Contrastive Refinement）}保留基础目标，并对该候选池计算单独加权的对比损失。其正负样本分数间隔形式使间隔较小或为负的候选产生更强优化压力。这两个阶段得到保留全库双编码器检索的 \method{}-Global。\method{}-Rerank 启用\textbf{双粒度重排（Dual-Granularity Reranking）}：词元级 MaxSim 与\textbf{全局—局部分数融合（Global--Local Score Fusion）}仅重新排序检索得到的前 \(K\) 个候选，不增加可训练参数，但会带来推理成本。

Under a matched local protocol on all six CodeSearchNet languages~\citep{CodeSearchNet}, \method{}-Global raises macro MRR from 79.8 to 80.6 and R@1 from 70.7 to 71.9; \method{}-Rerank reaches 81.1 MRR and 72.6 R@1. Budget-matched controls favor retriever-mined Failure Candidates over random and static alternatives, and the largest gains occur when the paired code initially ranks 2--10. Paired-bootstrap intervals quantify test-query sampling uncertainty for the fixed checkpoints, while three encoder instantiations test pipeline compatibility and the matched reranking benefit.
% 中文：在全部六种 CodeSearchNet 语言~\citep{CodeSearchNet}上的协议一致本地评测中，\method{}-Global 将宏平均 MRR 从 79.8 提升至 80.6，并将 R@1 从 70.7 提升至 71.9；\method{}-Rerank 达到 81.1 MRR 和 72.6 R@1。预算匹配的对照表明，检索器挖掘的失败候选优于随机和静态替代方案；当配对代码初始位于第 2--10 名时，收益最大。配对 bootstrap 区间衡量固定检查点上的测试查询采样不确定性，三种编码器实例则检验流程兼容性和协议一致的重排收益。

\noindent Our contributions are threefold:
% 中文：本文的贡献有三点：

\noindent First, we identify a supervision mismatch between conventional negative construction and the high-scoring comparisons exposed by a trained retriever's full-corpus ranking. Rank-conditioned analysis shows that the largest observed gains arise in near-top Retrieved-but-Mis-ranked Cases.
% 中文：第一，我们发现常规负样本构造与训练完成的检索器在全库排序中暴露的高分比较之间存在监督错位。按排名分层的分析表明，最大的观测收益来自接近顶部的“已检索但排序错误案例”。

\noindent Second, we introduce \method{}, which turns the frozen initial retriever's query-specific rankings into Failure Candidate Pools and applies a separate, margin-sensitive contrastive objective. \method{}-Global retains full-corpus retrieval, and \method{}-Rerank incorporates token-level evidence within the top-\(K\).
% 中文：第二，我们提出 \method{}，将冻结初始检索器的逐查询排序转化为失败候选池，并应用独立的、对分数间隔敏感的对比目标。\method{}-Global 保留全库检索，\method{}-Rerank 则在前 \(K\) 个候选内融合词元级证据。

\noindent Third, in a controlled six-language evaluation, \method{}-Global improves the matched initial retriever by 0.8 MRR points, and \method{}-Rerank raises the complete improvement to 1.3 points, with uncertainty and efficiency reported explicitly.
% 中文：第三，在六语言受控评测中，\method{}-Global 相对于协议一致的初始检索器提升 0.8 个 MRR 点，\method{}-Rerank 将完整系统的提升扩大至 1.3 个点，并显式报告不确定性与效率。

\section{Related Work}
\label{sec:related_work}

\subsection{Code Search}

\paragraph{Pre-trained code representations.}
Code search progressed from lexical, structural, and API-aware matching~\citep{Sourcerer,Portfolio,CodeHow} to neural systems that learn shared query--code representations~\citep{DeepCS,UNIF}. Subsequent work incorporated token overlap, program structure, contextual translation, relevance matching, and cross-domain adaptation~\citep{OCoR,TabCS,TranCS,CSRS,CDCS}. Pre-trained models further strengthened these representations: CodeBERT learns from bimodal code--text context, GraphCodeBERT injects data flow, and UniXcoder unifies cross-modal pre-training~\citep{CodeBERT,GraphCodeBERT,UniXcoder}; PLBART and CodeT5 extend pre-training across understanding and generation tasks~\citep{PLBART,CodeT5}, while UniCoR targets cross-language retrieval~\citep{UniCoR}. These models support efficient full-corpus search by precomputing code representations.
% 中文：代码搜索从基于词法、结构和 API 感知的匹配方法~\citep{Sourcerer,Portfolio,CodeHow}，发展到学习共享查询—代码表示的神经系统~\citep{DeepCS,UNIF}。后续工作进一步融合词元重叠、程序结构、上下文翻译、相关性匹配和跨领域适配~\citep{OCoR,TabCS,TranCS,CSRS,CDCS}。预训练模型进一步强化了这些表示：CodeBERT 从代码—文本双模态上下文中学习，GraphCodeBERT 注入数据流信息，UniXcoder 统一跨模态预训练~\citep{CodeBERT,GraphCodeBERT,UniXcoder}；PLBART 与 CodeT5 将预训练扩展到理解和生成任务~\citep{PLBART,CodeT5}，UniCoR 则面向跨语言检索~\citep{UniCoR}。这些模型通过预计算代码表示来支持高效的全库搜索。

\paragraph{Contrastive code retrieval.}
Contrastive methods strengthen code--text alignment through syntax-guided multimodal learning, large-scale paired pre-training, momentum encoders, semantics-preserving transformations, and augmented views~\citep{SynCoBERT,CodeRetriever,CoCoSoDa,Corder,ContraCode,ContraBERT}. Their objectives improve the representations learned during initial training.
% 中文：对比式方法通过语法引导的多模态学习、大规模配对预训练、动量编码器、语义保持变换和增强视图来强化代码—文本对齐~\citep{SynCoBERT,CodeRetriever,CoCoSoDa,Corder,ContraCode,ContraBERT}。这些目标改进初始训练阶段学习到的表示。

\paragraph{Negative-aware training.}
Negative-aware objectives further change how contrastive competitors are selected or weighted. Soft-InfoNCE downweights negative pairs according to estimated relevance~\citep{SoftInfoNCE}; uncertainty-aware training combines hard-negative sampling with confidence information~\citep{AAAIUA}; and HedgeCode adds auxiliary relevance supervision~\citep{HedgeCode}. Related systems mine or synthesize difficult examples during training~\citep{CoCoHaNeRe,R2PS}. The Category column in Table~\ref{tab:main_results} records this progression from pre-trained representations to contrastive retrieval and negative-aware training; each category denotes a model's primary emphasis rather than an exclusive capability.
% 中文：负样本感知目标进一步改变对比竞争项的选择或加权方式。Soft-InfoNCE 根据估计相关性降低负样本对的权重~\citep{SoftInfoNCE}；不确定性感知训练将困难负例采样与置信信息结合~\citep{AAAIUA}；HedgeCode 则加入辅助相关性监督~\citep{HedgeCode}。相关系统也会在训练期间挖掘或合成困难样本~\citep{CoCoHaNeRe,R2PS}。表~\ref{tab:main_results} 的 Category 列记录了从预训练表示、对比式检索到负样本感知训练的演进；每个类别表示模型的主要侧重点，而非互斥能力。

\subsection{Retriever Feedback and Refinement}

Hard-negative mining in dense text retrieval draws supervision from retrieved negatives, refreshed indexes, large candidate pools, and denoising~\citep{DPR,ANCE,HardNegDR,RocketQA}. We use \emph{retriever feedback} to denote the offline full-corpus ranking produced by a frozen initial retriever. \method{} obtains this signal after initial training, converts the query-specific high-ranked unpaired candidates into a fixed Failure Candidate Pool, and uses the pool in a separate refinement stage. Candidate discovery and parameter updates are thereby separated. In Table~\ref{tab:main_results}, the \method{} rows are categorized as retriever feedback and appear in the matched local block after the progression from pre-trained representations to contrastive and negative-aware training. \emph{Failure Candidate} is an operational label for a high-ranked unpaired competitor; benchmark pairing leaves its semantic validity unspecified.
% 中文：在稠密文本检索中，困难负例挖掘通过检索负例、索引刷新、大规模候选池和去噪获得监督~\citep{DPR,ANCE,HardNegDR,RocketQA}。本文使用\emph{检索器反馈（retriever feedback）}指代冻结初始检索器离线产生的全库排序。\method{} 在初始训练完成后获取这一信号，将逐查询的高排名未配对候选转化为固定的失败候选池，并在独立的细化阶段使用该候选池，由此将候选发现与参数更新分开。表~\ref{tab:main_results} 将 \method{} 行归入检索器反馈类别，并置于协议一致的本地评测区块中，以承接从预训练表示、对比式检索到负样本感知训练的演进。\emph{失败候选（Failure Candidate）}是高排名未配对竞争项的操作性标签；其语义有效性无法由基准配对关系确定。

\subsection{Late Interaction and Reranking}

Fine-grained code-search models use co-attention and cross-modal features to distinguish closely related snippets~\citep{FcarCS,FineGrainedCS,HedgeCode}. Late interaction retains token representations and aggregates token-wise similarities; ColBERT's MaxSim is representative~\citep{ColBERT}. \method{} preserves global representations for training and full-corpus retrieval, then applies MaxSim within the retrieved top-\(K\) when Dual-Granularity Reranking is enabled. Global--Local Score Fusion combines the standardized scores without additional trainable parameters, while incurring measurable inference cost.
% 中文：细粒度代码搜索模型利用协同注意力与跨模态特征区分高度相近的代码片段~\citep{FcarCS,FineGrainedCS,HedgeCode}。后期交互保留词元表示并聚合逐词元相似度，ColBERT 的 MaxSim 是代表性形式~\citep{ColBERT}。\method{} 在训练与全库检索中保留全局表示，并在启用双粒度重排时对检索得到的前 \(K\) 个候选应用 MaxSim。全局—局部分数融合在不增加可训练参数的情况下组合标准化分数，同时带来可测量的推理开销。

\section{Method}
\label{sec:method}

Figure~\ref{fig:framework} summarizes the three stages of \method{}. Failure Candidate Harvesting converts the frozen initial retriever's high-ranked unpaired alternatives into query-specific Failure Candidate Pools, and Failure-Calibrated Contrastive Refinement uses these pools to update the global retrieval space. Together they define \method{}-Global, which retrieves from the complete corpus. \method{}-Rerank additionally applies Dual-Granularity Reranking to combine sequence-level and token-level evidence within the retrieved top-\(K\).
% 中文：图~\ref{fig:framework} 概述了 \method{} 的三个阶段。失败候选挖掘将冻结初始检索器返回的高排名未配对替代项转化为逐查询的失败候选池，失败校准对比细化利用这些候选池更新全局检索空间。二者共同构成从完整语料库检索的 \method{}-Global；\method{}-Rerank 进一步应用双粒度重排，在检索得到的前 \(K\) 个候选内融合序列级与词元级证据。

\subsection{Problem Formulation}
\label{sec:problem_formulation}

Let \(\mathcal{D}=\{(q_i,c_i^+)\}_{i=1}^{N}\) denote a code-search training set, where \(q_i\) is a natural-language query and \(c_i^+\) is its paired code snippet. A dual encoder maps queries and code into a shared space through \(f_\theta\) and \(g_\theta\). After \(\ell_2\) normalization, their global retrieval score is
% 中文：设 \(\mathcal{D}=\{(q_i,c_i^+)\}_{i=1}^{N}\) 表示代码搜索训练集，其中 \(q_i\) 是自然语言查询，\(c_i^+\) 是与之配对的代码片段。双编码器分别通过 \(f_\theta\) 和 \(g_\theta\) 将查询与代码映射到共享空间。经过 \(\ell_2\) 归一化后，其全局检索分数定义为
\begin{equation}
  s_\theta(q,c)=f_\theta(q)^{\top}g_\theta(c).
  \label{eq:global_score}
\end{equation}

For a competing candidate \(c^-\), define the score margin as
% 中文：对于竞争候选 \(c^-\)，分数间隔定义为
\begin{equation}
  \mu_\theta(q_i,c^-)
  =s_\theta(q_i,c_i^+)-s_\theta(q_i,c^-).
  \label{eq:score_margin}
\end{equation}
The rank of the paired code can then be written as
% 中文：配对代码的排名可写为
\begin{equation}
  \operatorname{rank}_\theta(c_i^+\mid q_i)
  =1+\sum_{c\in\mathcal{C}\setminus\{c_i^+\}}
  \mathbb{I}\!\left[\mu_\theta(q_i,c)\leq 0\right],
  \label{eq:rank_margin}
\end{equation}
where \(\mathcal{C}\) is the retrieval corpus. Equations~\ref{eq:score_margin} and~\ref{eq:rank_margin} make the relevant score comparisons explicit: a negative margin identifies a candidate that already outranks the paired code, while a small positive margin identifies a nearby competitor whose order can be reversed by a modest score change. Both are more informative for refinement than candidates already separated by a large margin. Conventional in-batch or statically mined negatives are selected before the final retriever is observed and need not coincide with these model-specific competitors. \method{} therefore conditions refinement on the ranking behavior of a trained initial retriever.
% 中文：其中 \(\mathcal{C}\) 表示检索语料库。式~\ref{eq:score_margin} 与式~\ref{eq:rank_margin} 明确了与排序相关的分数比较：负间隔表示某个候选已经排在配对代码之前，较小的正间隔则表示一个只需较小分数变化就可能发生次序逆转的邻近竞争候选。与已经被大间隔分开的候选相比，这两类候选能为细化提供更有针对性的信息。常规批内负例或静态挖掘负例是在最终检索器行为被观察之前选取的，因此未必与这些模型特定的竞争候选一致。基于此，\method{} 根据训练完成的初始检索器所产生的排序行为开展细化。

Competitors are query dependent: a code snippet may rank low for one query yet highly for another. Refinement therefore associates each query with candidates from its own corpus ranking, preserving the link between observed scores and subsequent contrastive comparisons.
% 中文：竞争候选依赖于具体查询：同一代码片段在一个查询下可能排名较低，却可能在另一个查询下排名很高。因此，细化为每个查询关联其自身语料库排序中的候选，从而保留观测分数与后续对比比较之间的对应关系。

\subsection{Failure Candidate Harvesting}
\label{sec:failure_harvesting}

We first train an initial retriever with the underlying contrastive code-search objective and freeze its parameters \(\theta_0\). For every training query, the frozen model retrieves from the training code corpus. Let \(\mathcal{E}_i\) contain the paired code and all candidates sharing its URL. We remove \(\mathcal{E}_i\) and retain the \(M\) highest-scoring candidates:
% 中文：我们首先使用基础对比式代码搜索目标训练初始检索器，并冻结其参数 \(\theta_0\)。对于每个训练查询，冻结模型在训练代码语料库中执行检索。令 \(\mathcal{E}_i\) 包含配对代码以及与其共享 URL 的所有候选；移除 \(\mathcal{E}_i\) 后，保留得分最高的 \(M\) 个候选：
\begin{equation}
  \begin{aligned}
    \mathcal{H}_i
    &=\operatorname{Top}_{M}^{s_{\theta_0}(q_i,\cdot)}
      (\mathcal{C}_{\mathrm{train}}\setminus\mathcal{E}_i), \\
    \mathcal{F}_i
    &=\operatorname{Top}_{m}^{s_{\theta_0}(q_i,\cdot)}(\mathcal{H}_i).
  \end{aligned}
  \label{eq:fc_pool}
\end{equation}

We call \(\mathcal{F}_i\) the \emph{Failure Candidate Pool} for \(q_i\), and its members \emph{Failure Candidates}. They are the initial retriever's strongest unpaired alternatives and directly instantiate the score comparisons that determine rank in Equation~\ref{eq:rank_margin}. This operational designation follows benchmark pairing and retrieval rank; it does not assume that every unpaired candidate is semantically invalid. The two truncation levels serve different roles. \(M\) bounds the harvested pool produced by corpus retrieval, whereas \(m\) defines the high-ranked Failure Candidate Pool exposed to refinement; sampling \(r\) entries from that pool controls the additional per-update comparison budget. The pool is generated once from the frozen initial retriever, preserving model specificity without repeating corpus-wide retrieval at every update. Freezing \(\theta_0\) also separates candidate discovery from parameter updates: candidate identities and their initial order remain fixed while \(\theta\) changes during refinement.
% 中文：我们将 \(\mathcal{F}_i\) 称为查询 \(q_i\) 的\emph{失败候选池（Failure Candidate Pool）}，并将其中元素称为\emph{失败候选（Failure Candidates）}。它们是初始检索器返回的最强未配对替代项，并直接构成式~\ref{eq:rank_margin} 中决定排名的分数比较。该操作性名称依据基准配对关系与检索排名给出，并不假设每个未配对候选在语义上都无效。两个截断层次具有不同作用：\(M\) 限制全库检索所得挖掘池的规模，\(m\) 则定义细化阶段可见的高排名失败候选池；从该候选池采样 \(r\) 个条目用于控制每次更新新增的比较预算。候选池仅由冻结的初始检索器生成一次，从而保留模型特异性，同时避免在每次参数更新时重复执行全语料库检索。冻结 \(\theta_0\) 还将候选发现与参数更新分开：在细化过程中，候选身份及其初始次序保持固定，而 \(\theta\) 持续更新。

\subsection{Failure-Calibrated Contrastive Refinement}
\label{sec:failure_refinement}

Starting from \(\theta_0\), we retain the initial retriever's contrastive objective \(\mathcal{L}_{\mathrm{base}}\) and introduce a listwise objective over the harvested candidates. For a minibatch \(\mathcal{B}\), let \(\mathcal{S}_i\subseteq\mathcal{F}_i\) contain the \(r\) candidates sampled for query \(q_i\). The failure-candidate loss is
% 中文：以 \(\theta_0\) 为起点，我们保留初始检索器的对比目标 \(\mathcal{L}_{\mathrm{base}}\)，并对挖掘得到的候选引入 listwise 目标。对于小批量 \(\mathcal{B}\)，设 \(\mathcal{S}_i\subseteq\mathcal{F}_i\) 包含为查询 \(q_i\) 采样的 \(r\) 个候选。失败候选损失定义为
\begin{equation}
  \mathcal{L}_{\mathrm{FC}}^{i}
  =-\log
  \frac{\exp(s_\theta(q_i,c_i^+)/\tau_f)}
  {\begin{aligned}
     &\exp(s_\theta(q_i,c_i^+)/\tau_f) \\
     &\quad+\sum_{c\in\mathcal{S}_i}
       \exp(s_\theta(q_i,c)/\tau_f)
   \end{aligned}},
  \label{eq:fc_loss}
\end{equation}
and the complete refinement objective is
% 中文：完整的细化目标为
\begin{equation}
  \mathcal{L}_{\mathrm{ref}}
  =\mathcal{L}_{\mathrm{base}}
  +\frac{\lambda_f}{|\mathcal{B}|}
   \sum_{i\in\mathcal{B}}\mathcal{L}_{\mathrm{FC}}^{i}.
  \label{eq:refinement_loss}
\end{equation}

Equation~\ref{eq:refinement_loss} computes \(\mathcal{L}_{\mathrm{FC}}\) separately from \(\mathcal{L}_{\mathrm{base}}\). The coefficient \(\lambda_f\) controls only the added failure-candidate signal and leaves the base softmax unchanged.
% 中文：式~\ref{eq:refinement_loss} 将 \(\mathcal{L}_{\mathrm{FC}}\) 与 \(\mathcal{L}_{\mathrm{base}}\) 分开计算。系数 \(\lambda_f\) 只控制新增的失败候选信号，并保持基础 softmax 不变。

\paragraph{Score-margin interpretation.}
The added term admits a direct score-margin form,
% 中文：新增损失项可直接写成分数间隔形式：
\begin{equation}
  \mathcal{L}_{\mathrm{FC}}^{i}
  =\log\!\left(1+\sum_{c\in\mathcal{S}_i}
  \exp[-\mu_\theta(q_i,c)/\tau_f]\right).
  \label{eq:margin_loss}
\end{equation}
Candidates with smaller or negative margins consequently exert greater optimization pressure: their exponential terms occupy more mass in Equation~\ref{eq:margin_loss}, producing a larger-magnitude gradient with respect to the corresponding margin. The coefficient \(\lambda_f\) calibrates this targeted signal against the initial retriever's training objective. Training uses only global representations; token-level local interaction and CTRD are not part of the refinement objective.
% 中文：因此，分数间隔更小或为负的候选会产生更强的优化压力：它们的指数项在式~\ref{eq:margin_loss} 中占据更大权重，从而对相应分数间隔产生幅度更大的梯度。系数 \(\lambda_f\) 用于校准这一针对性信号相对于初始检索器训练目标的权重。训练仅使用全局表示；词元级局部交互和 CTRD 不属于细化目标。

\subsection{Dual-Granularity Reranking}
\label{sec:reranking_method}

Global retrieval remains responsible for searching the complete corpus. \method{}-Rerank resolves fine-grained distinctions among its top-\(K\) candidates with MaxSim~\citep{ColBERT}. Let \(\{\mathbf{h}^{q}_{a}\}_{a=1}^{T_q}\) and \(\{\mathbf{h}^{c}_{b}\}_{b=1}^{T_c}\) be the token representations of a query and candidate code. Their local-interaction score is
% 中文：全局检索仍负责在完整语料库中进行搜索。\method{}-Rerank 使用 MaxSim~\citep{ColBERT} 解析其前 \(K\) 个候选之间的细粒度差异。设 \(\{\mathbf{h}^{q}_{a}\}_{a=1}^{T_q}\) 和 \(\{\mathbf{h}^{c}_{b}\}_{b=1}^{T_c}\) 分别为查询与候选代码的词元表示，其局部交互分数为
\begin{equation}
  s_m(q,c)=\frac{1}{T_q}\sum_{a=1}^{T_q}
  \max_{1\leq b\leq T_c}
  \cos(\mathbf{h}^{q}_{a},\mathbf{h}^{c}_{b}).
  \label{eq:maxsim}
\end{equation}

Because global and token-level scores have different query-dependent scales, each is standardized over the same top-\(K\) set. The final score is
% 中文：由于全局分数与词元级分数具有不同且依赖查询的数值尺度，我们在同一前 \(K\) 候选集合内分别对二者进行标准化。最终分数定义为
\begin{equation}
  s_r(q,c)=\alpha\widetilde{s}_\theta(q,c)
  +(1-\alpha)\widetilde{s}_m(q,c).
  \label{eq:fusion}
\end{equation}
Only candidates inside the top-\(K\) set are reordered; all remaining corpus items preserve their global-retrieval order. This stage adds no trainable parameters and is selected independently from the training objective. Its token-level interactions add inference cost, measured in Section~\ref{sec:efficiency}.
% 中文：只有前 \(K\) 集合内的候选会被重新排序，其余语料库条目保持全局检索产生的顺序。该阶段不增加可训练参数，并与训练目标独立选择。其词元级交互会增加推理开销，相关测量见第~\ref{sec:efficiency} 节。

\section{Experiments}
\label{sec:experiments}

Our evaluation asks whether retriever feedback improves the initial retriever and where the gain comes from. We first establish matched effectiveness across six languages, then separate training-time refinement from MaxSim reranking, vary the source and configuration of Failure Candidate Pools, and locate changes by the paired code's initial rank. Encoder instantiations test compatibility, while validation sweeps and latency measurements characterize the optional reranker. Paired bootstrap intervals quantify test-query sampling uncertainty for the fixed checkpoints.
% 中文：我们的评测考察检索器反馈能否改进初始检索器，以及这一收益来自哪里。我们首先在六种语言上建立协议一致的效果比较，随后区分训练阶段细化与 MaxSim 重排的贡献，改变失败候选池的来源与配置，并根据配对代码的初始排名定位性能变化。编码器实例用于检验兼容性，验证集扫描与延迟测量则刻画可选重排器。配对 bootstrap 区间衡量固定检查点上的测试查询采样不确定性。

\method{}-Global performs full-corpus dual-encoder retrieval. \method{}-Rerank computes MaxSim only for the retrieved top-\(K\) and combines the per-query standardized global and token-level scores as \(\alpha\widetilde{s}_g+(1-\alpha)\widetilde{s}_m\). Six-language macro validation MRR selects \(K=20\) and \(\alpha=0.5\); both values and all model checkpoints are fixed before test evaluation.
% 中文：\method{}-Global 执行全库双编码器检索。\method{}-Rerank 仅对检索得到的前 \(K\) 个候选计算 MaxSim，并按照 \(\alpha\widetilde{s}_g+(1-\alpha)\widetilde{s}_m\) 融合逐查询标准化后的全局分数与词元级分数。六语言宏平均验证集 MRR 选出 \(K=20\) 和 \(\alpha=0.5\)；这两个取值与所有模型检查点均在测试集评测前固定。

The encoder-instantiation experiments preserve the same harvesting, refinement, and reranking design. GraphCodeBERT retains data-flow-aware inputs, while its MaxSim score uses lexical tokens and excludes data-flow nodes. Appendix~\ref{app:experimental_details} reports encoder-specific input lengths and optimization settings.
% 中文：编码器实例化实验保持相同的候选挖掘、细化与重排设计。GraphCodeBERT 保留数据流感知输入，其 MaxSim 分数使用词法词元并排除数据流节点。各编码器特定的输入长度与优化设置见附录~\ref{app:experimental_details}。

We estimate 95\% confidence intervals for paired MRR differences by stratified paired bootstrap over test queries. These intervals quantify finite-test-sample uncertainty for fixed checkpoints. All paired differences compare the three protocol-matched local systems in Table~\ref{tab:main_results}; cited prior-work rows are excluded. Appendix~\ref{app:experimental_details} documents split isolation, candidate-cache validity, checkpoint provenance, and validation-only selection.
% 中文：我们在测试查询上采用分层配对 bootstrap，为配对 MRR 差值估计 95\% 置信区间。这些区间衡量固定检查点下有限测试样本带来的不确定性。所有配对差值均比较表~\ref{tab:main_results} 中三项协议一致的本地系统，不包含引用的既有工作行。附录~\ref{app:experimental_details} 记录数据划分隔离、候选缓存有效性、检查点来源和仅使用验证集的选择过程。

\subsection{Overall Retrieval Effectiveness}
\label{sec:main_results}

Table~\ref{tab:main_results} anchors the effectiveness claim in the matched local comparison. \method{}-Global raises macro MRR from 79.8 to 80.6, and validation-selected MaxSim reranking further raises it to 81.1, for absolute gains of 0.8 and 1.3 points. MRR increases in every language: by 0.6--1.2 points for Global refinement and 1.0--1.7 points for the complete system.
% 中文：表~\ref{tab:main_results} 以协议一致的本地比较支撑效果主张。\method{}-Global 将宏平均 MRR 从 79.8 提升至 80.6，经验证集选定的 MaxSim 重排进一步将其提高到 81.1，绝对增益分别为 0.8 和 1.3 个点。全部六种语言的 MRR 均有提升：Global 细化提高 0.6--1.2 个点，完整系统提高 1.0--1.7 个点。

The recall pattern places the main change at the first position. From the initial retriever to \method{}-Rerank, R@1 increases from 70.7 to 72.6 and R@5 from 91.3 to 91.7, while R@10 remains 95.1 at the displayed precision. This pattern is consistent with reordering Retrieved-but-Mis-ranked Cases near the top rather than expanding retrieval coverage at deeper ranks. The following controlled analyses identify the contributions of refinement and reranking, the role of retriever feedback, and the initial-rank groups in which the changes occur.
% 中文：召回率模式表明主要变化发生在首位。从初始检索器到 \method{}-Rerank，R@1 从 70.7 提升至 72.6，R@5 从 91.3 提升至 91.7，而 R@10 在当前显示精度下保持 95.1。该模式与重新排序顶部附近的“已检索但排序错误案例”一致，而非扩大更深排名处的检索覆盖。下文的受控分析进一步识别细化与重排的贡献、检索器反馈的作用，以及变化发生在哪些初始排名分组中。

\section{Conclusion}
\label{sec:conclusion}

We presented \method{}, which turns the fixed full-corpus rankings of an initial retriever into query-specific Failure Candidate Pools and margin-sensitive contrastive refinement. \method{}-Global retains full-corpus dual-encoder retrieval, while \method{}-Rerank confines Dual-Granularity Reranking to the top-\(K\) and exposes an explicit effectiveness--latency trade-off. Under a matched six-language CodeSearchNet protocol, refinement raises macro MRR from 79.8 to 80.6 and the complete system reaches 81.1. Candidate controls favor retriever-harvested supervision over equal-budget random and static alternatives, while rank-conditioned analysis locates the largest gains at initial ranks 2--10. The resulting second-stage supervision is tied directly to the high-score comparisons exposed by the initial retriever.
% 中文：本文提出 \method{}，将初始检索器固定的全库排序转化为逐查询失败候选池和对分数间隔敏感的对比细化。\method{}-Global 保留全库双编码器检索，\method{}-Rerank 则将双粒度重排限制在前 \(K\) 个候选内，并呈现明确的效果—延迟权衡。在六语言 CodeSearchNet 的协议一致评测中，细化将宏平均 MRR 从 79.8 提升至 80.6，完整系统达到 81.1。候选对照表明，检索器挖掘监督优于等预算的随机与静态替代方案；按排名分层的分析则将最大收益定位于初始第 2--10 名。由此得到的第二阶段监督直接对应初始检索器暴露的高分比较。

\section*{Limitations}

Evaluation is limited to CodeSearchNet and one training seed (123456). The paired-bootstrap intervals describe test-query sampling uncertainty for fixed checkpoints and do not measure variation across retraining runs. Because CodeSearchNet supplies one paired code snippet per query, some high-ranked unpaired candidates may be valid alternative implementations; \emph{Failure Candidate} is an operational retrieval label without a semantic judgment. The encoder experiments support end-to-end compatibility and within-checkpoint reranking benefits, while protocol-matched refinement gains require locally evaluated initial checkpoints under the same encoder-specific settings. MaxSim adds no trainable parameters, but its top-\(K\) token interactions increase inference latency.
% 中文：评测仅覆盖 CodeSearchNet，并只使用一个训练随机种子（123456）。配对 bootstrap 区间描述固定检查点下的测试查询采样不确定性，不衡量不同重新训练运行之间的变化。由于 CodeSearchNet 每个查询只提供一个配对代码片段，部分高排名未配对候选可能是有效替代实现；\emph{失败候选（Failure Candidate）}是一个不带语义判断的操作性检索标签。编码器实验支持端到端兼容性和同一检查点内的重排收益；协议一致的细化收益仍需要在相同编码器特定设置下对初始检查点进行本地评测。MaxSim 不增加可训练参数，但其前 \(K\) 候选词元交互会增加推理延迟。
